### 1. Microsoft 365 E7 の割引プロモーションが 10/1 に終了する — Copilot 同梱 SKU の見積もりは 9/30 が実質の期限

**要点**: E7 の販売促進割引は 10/1 以降、新規取引ができなくなる。対象購入の最終日は 9/30 である。Copilot 同梱 SKU を割引前提で組んでいた提案は、定価前提へ引き直すか 9 月中に確定させるかの二択に変わる。

**詳細**: Partner Center の8月アナウンスページが公開された（掲載3件・いずれも 8/3 付）。8/4 時点では 404 で未公開だった。M365 プロモーションの変更は E7 と E3 で逆方向に動いている。

- 終了する E7 プロモーション3本: 10% off 1年 / 15% off 1年 / 15% off 3年。対象顧客の購入は 9/30 まで可能で、10/1 以降は新規のプロモーション取引ができない。**購入済みのサブスクリプションは契約条件どおり継続**する
- 延長される E3 プロモーション2本: 10% off 3年（新規向け）と 20% off 1年（ターゲット向け）が、いずれも **12/31 まで**利用できる
- Microsoft は理由として、プロモーション取引中心の投資から「growth margin」（継続利用と展開成功に報いる仕組み）への移行を挙げている

E7 は M365 E5 に Copilot を同梱した SKU で、5/1 に Agent 365 とあわせて GA した。Copilot の全社展開を E7 の割引前提で見積もっている場合、影響を受ける。

- https://learn.microsoft.com/en-us/partner-center/announcements/2026-august

### 2. GitHub Copilot ハーネスは 8/3 に GA していた — Learn の What's New は今も Preview 表記のまま

**要点**: GitHub Copilot ハーネスとワークフローデザイナーが 8/3 付で GA し、本番利用できるようになった。前提が「Preview を評価する段階」から「本番投入してよい段階」へ変わる。ただし Learn 側の記載は追随していない。

**詳細**: 昨日は techcommunity が 403 で記事本文を取得できず、課金仕様だけを Learn の一次ページから確認していた。本日 403 が解けたため、発表記事の本文を一次で確認できた。

- GA の対象は2つで、GitHub Copilot ハーネス本体（本番利用可）と、ワークフローデザイナー（ビジュアルキャンバス、エージェントノードの追加、ワークフロー評価の実行）である
- 稼働モデルとして **Opus 5・GPT-5.6 Sol・Fable 5** が挙げられている。ハーネスは GitHub Copilot SDK を基盤とする
- 標準ハーネスとの比較テストで、マルチツール利用・ファイル解析・コード解析・ナレッジ品質の4点で改善が出たとしている
- 課金は M365 Copilot ライセンスの有無にかかわらず使用量ベースで、自然言語オーサリングと評価も消費対象に含まれる（8/4 掲載の課金仕様と一致）
- 自然言語での複数ターン対話によるオーサリングは「coming soon」と記載され、まだ提供されていない

一方、Learn の Copilot Studio What's New は本日時点でも June 2026 節に `(Production-ready preview)` と書いたままで、GA が反映されていない。**What's New の文言だけで提供段階を判定すると誤る**状態が現に発生しているため、検知手順の不備として B-023 を起票した。
