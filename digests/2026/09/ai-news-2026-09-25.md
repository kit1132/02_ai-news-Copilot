### 1. [新機能] Release Notes に29日ぶりの新バッチ（25項目）が載り、Federated Copilot Connectors が GA した — MCP コネクタと Outlook の書き込み操作が本番扱いになる

**要点**: Release Notes の September 23 バッチ（8/26〜9/22 のリリース分）で、MCP ベースの Federated Copilot Connectors が GA した。同じバッチで、Outlook の Copilot がメールの削除・移動やルール作成を行えるようになった。Copilot が外部 SaaS をリアルタイムに読み、メールボックスを書き換える機能が Preview から本番機能に変わった。

**詳細**: 先頭の H2 が **September 23, 2026** になった（`updated_at` **2026-09-24T18:53Z**・`git_commit_id` `7a57bcbb`）。前バッチは August 25 で、H2 は83本から84本に増えた。25項目のうち管理・統制に関わるものは次のとおり。

- Federated Copilot Connectors（Roadmap **501120**）: 顧客データを Microsoft 側に保存・索引化せず、ユーザー本人の ID で MCP 経由のリアルタイム取得を行う。対応面は Researcher / M365 Chat / Excel の Copilot 編集で、統制は M365 管理センターで行う。9/24 掲載の書き込み対応（570964・GA 10月）は、この GA が前提になる
- Outlook のトリアージ操作: Copilot がメールの削除・移動・コピー・分類に加え、受信トレイのルール作成・フォルダー作成まで自然言語で行う。**6通以上**を操作するときと、ルールを変更するときは確認を求める。対象は Classic / New Outlook・Web・Mac・モバイル
- License Requests ページ（**561206**）: 管理者が、ユーザーから届いた M365 Copilot ライセンス申請を専用ページで並べ替え・絞り込み・一括承認できる
- GitHub Copilot AI コストダッシュボード（**566470**）: Workplace Analytics の Insights に、GitHub Copilot の消費量・コスト・導入指標が1画面でまとまった。予算に対する支出を追跡できる
- People Skills の全削除（**565905**）: 管理者がテナントのスキルデータを一括で完全削除できる。削除後は Copilot と Viva の体験で使われなくなる
- 残りの項目: 会議の議事録検索（直近2か月）、Forms の Copilot チャットペイン（553136）、画面共有・モバイルカメラの Vision（561037）、Copilot Notebooks の新デザイン（562662）、PowerPoint のユーザー定義スキル、Planner Agent チャット（560532）、classic Outlook での宣言型エージェント拡張（481559）、Viva の日次利用レポート（561325）など

### 2. [料金] 非営利団体が M365 Copilot で非営利割引と商用プロモーションを併用できるようになった — 「どちらか一方」から「上乗せ」へ変わる

**要点**: 対象の非営利団体は、M365 Copilot SKU に含まれる非営利プロモーション15%に、15% / 20% / 30% / 40% の CSP プロモーションを上乗せできるようになった。これまでは非営利価格か商用プロモーションのどちらかしか選べなかった。期限は **2026-12-31** なので、非営利顧客向けの見積もりは引き直しが要る。

**詳細**: Partner Center の9月アナウンス（**9/24** 付・`updated_at` 2026-09-24T16:05Z・`git_commit_id` `ef9e29b1`）が告知した。対象は、非営利顧客を扱う CSP ディストリビューター、間接リセラー、直接請求パートナーである。取引前に顧客の適格性・ベース SKU・価格種別・プロモーション ID の要件を確認するよう求めており、詳細は CSP Nonprofit Copilot Readiness Kit と FAQ を参照先に挙げている。全 digest に掲載歴はない。
