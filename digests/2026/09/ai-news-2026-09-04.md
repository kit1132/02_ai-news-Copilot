### 1. Release Wave の製品別ページは消えていなかった — パスが改名されただけで、GA 検知の経路は生きている

**要点**: 昨日「4本が 404 で消滅し GA 検知の主経路が失われた」と判定したが、実体は URL のリネームだった。GA 判定を Roadmap の `status` へ緊急に移す必要はなく、期限は 11/15 の Release Planner 退役に戻る。

**詳細**: `power-platform/release-plan/2026wave1/` の索引ページ（HTTP 200）を読むと、各製品へのリンクが `power-apps/` `power-pages/` `power-automate/` `data-platform/` `power-platform-governance-administration/` の5本になっている。登録 URL にあった `microsoft-` 接頭辞が4本から外れており、新パスは `planned-features` まで含めて全て **HTTP 200** で取得できた。5ページとも `updated_at` **2026-09-03T14:35:00Z**・`git_commit_id` `06b3b6ba` で、8/28 から7日据え置かれていた `b92ae441` からの再ビルドが 9/3 に入っている。

- **リネームの対応**: `microsoft-power-automate` → `power-automate`、`microsoft-power-apps` → `power-apps`、`microsoft-power-pages` → `power-pages`、`microsoft-dataverse` → `data-platform`。`power-platform-governance-administration` だけは元からこの形で、昨日 1本だけ 200 だった理由もこれで説明がつく
- ⚠️ **旧パスは 301 も 308 も返さず、親ごと 404 になる。**転送先が示されないため、リダイレクト追跡でも WebSearch でも新パスには辿り着けず、**索引ページのリンクを読むまで判別できない**
- 昨日の記録は「サブツリーの親ごと 404 = 消滅」と読んだが、実際には**同じ階層に別名の親が新設されていた**。404 を見た時点で同一サブツリーの索引を読む手順があれば当日に判別できた（**B-055 の根拠を訂正**し、新パスへの差し替えを **B-056** として起票した）
- Copilot Studio 版だけは従来どおり `aka.ms/MCStoM365Roadmap` へ **301** で、`aka.ms` はゲートウェイ拒否のため到達できない（B-012）

### 3. Copilot Studio のエージェント作成がアプリ起点に作り替えられる（Roadmap 569474・GA 2026年10月）

**要点**: これまでの作成体験は「エージェントを作ってから知識とツールを足す」順序だったが、対象アプリの選択を起点に必要な機能を構成する順序に変わる。研修教材と社内手順書の作成フローは10月に書き直しが要る。

**詳細**: Release Communications の RSS に **9/2 22:56Z** 付で **569474**（`In development`・GA 2026年10月・Worldwide・Web）が新規起票された。記事は「Copilot Studio is evolving to an app-first agent creation experience」と書き、メーカーはエージェントが扱うアプリケーションから着手して必要な機能を構成する、ツールと知識をより統合された体験にまとめる、と説明する。同じバッチで **570433**（Preview 2026年10月 / GA 2026年11月）も起票され、こちらは **MCP Apps**（Model Context Protocol の拡張）で会話内にインタラクティブ UI を描画する。

- 570433 の対象は UI 対応ツールを持つ MCP サーバーで、ソート可能なテーブルやドリルダウンが会話内に直接描画される。UI を描画できない配置面にはプレーンテキストのフォールバックが返り、**メーカー側の作業は準拠 MCP サーバーを接続するだけ**とされる
- M365 Copilot 側の宣言型エージェントには 2026年3月から OpenAI Apps SDK 経由の UI ウィジェットがあり、Copilot Studio 側が MCP Apps で同じ層を持つ形になる
