## 今日のハイライト

### 1. [新機能] GPT-6.2 Sol が Word・Excel・PowerPoint・Chat に M365 Copilot ライセンスの範囲で入り、Astra は OpenAI サブプロセッサーが有効なテナントに限られる — どのモデルが使えるかは、ライセンスと従量課金とサブプロセッサーの3つの設定で決まる

**要点**: Sol は M365 Copilot のライセンスの範囲で Office と Chat に GA で入る。ただし上限がある。Astra は従量課金のみで、OpenAI をサブプロセッサーとして無効にしたテナントではどの提供面でも使えない。

**詳細**: MC1560916（11/19）。
- GPT-6.2 Sol: Cowork と Copilot Studio は従量課金で GA。Word / Excel / PowerPoint / Chat は M365 Copilot のライセンスの範囲で GA で、上限がある（大半の利用者は達しない想定）
- GPT-6.2 Astra: Cowork と Copilot Studio は従量課金で GA。Word / Excel / PowerPoint / Chat は Frontier に入っていて従量課金が有効な利用者だけが使える
- 前提: 対象の利用者には既定でオンになる。Astra は OpenAI のサブプロセッサー設定が無効だと使えない。Microsoft が Azure OpenAI で運用するモデルはこの設定の影響を受けない
- Copilot Studio のモデル表には 11/19 に GA で載ったが、Cowork のモデル表（`75f8dadb`）にはまだ載っていない
- https://mc.merill.net/message/MC1560916

### 2. [破壊的変更] Copilot デスクトップアプリのアプリ内ブラウズが2027年1月に既定でオンになる — 止めたい組織は 1/3 までに BrowsingEnabled ポリシーを Off にする

**要点**: 今は任意の機能で、チャットで共有された Web サイトはアプリの外で開く。2027年1月からは Windows と Mac のアプリの中で、会話の横に開くのが既定になる。ポリシーを入れなければ有効のまま残る。

**詳細**: MC1560922（11/20・Major change・Act by 2027-01-03）。
- 展開: 全世界で2027年1月上旬に始まり、1月末に終わる予定である。元の機能は MC1474455 で告知されていた
- 無効にするには: デバイス管理で `BrowsingEnabled` を Off にする。セキュリティ・プライバシー・認証とネットワーク・ダウンロード・アクセス許可を個別に制御する新しいポリシーも用意される
- 関連ドキュメントは後で MC に追記するとしている
- https://mc.merill.net/message/MC1560922

### 3. [予定] Copilot Studio のワークフローで Python を実行するノードが 12/1 に GA になる — コネクタが無い API やファイル変換は、Copilot Credits を消費するコードの手順で書けるようになる

**要点**: 作成者は、ワークフローの手順として Python を AI に生成させるか、自分で書いて実行できるようになる。実行は Microsoft が管理するサンドボックスで、外部への API 呼び出しはできない。

**詳細**: MC1561862（11/20）・Roadmap 580866。同じ日に、ワークフロー関連の告知がほかにも出た。
- Code ノード（12/1 GA）: データ変換・PDF から text / CSV / XML への変換と解析・正規表現の処理に使う。Copilot Credits を消費する。MC は「コネクタが無い API の呼び出し」も用途に挙げるが、同じ MC が外部への API 呼び出しはできないとも書いており、両者は食い違っている
- Agent ノードからのファイル生成（MC1561859・12/3 GA・Roadmap 580865）: エージェントが作った PDF / Word / Excel / PowerPoint / CSV をワークフローの出力として渡し、メール送信や SharePoint への保存に使えるようになる
- Classify ノードの Decision モデル（MC1560402・11/19 GA）: 大量の分類を効率よく処理できる。既存の Classify ノードはモデルを変えるまで今の動作のまま残る
- Roadmap には、ワークフローを共同所有者と共有する機能（580864）とサービスプリンシパルを所有者にする機能（580863）も12月の予定で載った。サービスプリンシパル認証の GA（MC1557509・12/17）は既報である
- https://mc.merill.net/message/MC1561862
