# AI News Digest 2026-08-12

## 今日のハイライト

### 1. Agent 365 の Registry Sync が GA — エージェント棚卸しの範囲が Microsoft 製に閉じなくなった

**要点**: 管理者が Amazon Bedrock・Google Cloud Gemini・Anthropic Claude・Databricks Genie・Salesforce Agentforce のエージェントを Agent 365 レジストリへ同期できるようになった。テナント内のエージェント台帳は「Microsoft 製の一覧」から「全社の一覧」へ前提が変わる。

**詳細**: 出典は Agent 365 ブログの月次記事「What's new in Agent 365 – July 2026」（記事ID 4543654・2026-08-06 公開）。Registry sync は同期先プラットフォームを接続したうえで、エージェントとメタデータを**日次または週次**のいずれかの頻度でレジストリへ取り込む。基盤側 API が対応している範囲では、Agent 365 の画面からエージェント単位のガバナンス操作を直接実行できる。

あわせて同記事は、レジストリのリスク可視化にセキュリティパートナー3社（**Cyera・Darktrace・Zenity**）のシグナルを統合したことを案内している。

- シグナルの紐づけは **Microsoft Entra Agent ID** を identity anchor として行い、パートナー側の検知を正しいエージェントレコードに対応させる
- リスクは High / Medium / Low に分類され、発生パターンとあわせて統合ビューに表示される
- パートナー連携は任意で、⚠️ **管理者がパートナーリスクシグナルを有効化するまでパートナーへのデータ流入は発生しない**

- https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-agent-365-%E2%80%93-july-2026/4543654

### 2. マルチテナントのエージェント管理が Public Preview に入った — テナントごとに管理者アカウントを分ける前提が消える

**要点**: 管理者が、統制下の複数テナントのエージェントを M365 管理センターの単一画面から棚卸し・追加・インストール／ブロックできるようになった。サインアウトも別管理者アカウントの維持も不要になり、テナント横断のエージェント統制は個別ログインを前提としない形へ移る。

**詳細**: Partner Center の8月アナウンス（**8/10 付**）と Agent 365 ブログ（8/6）の2経路で確認した。対象は CSP ディストリビューター・CSP 間接リセラー・CSP 直接請求パートナーと SI / GSI。既存のテナント間管理関係と **GDAP**（Granular Delegated Admin Privileges）の上に載る仕組みで、操作は各顧客テナントにおける委任ロールのスコープ内に限られる。テナント固有のリスクとアクティビティのインサイトを見るには **Agent 365 ライセンス**が必要になる。

同じ 8/10 に **Microsoft Entra Tenant Governance が GA** し、企業側がこのテナント間関係を構成する経路も揃った。GA 版では Related Tenants（テナント関係の把握）、Governance Relationships（最小権限のテナント間委任管理）、Tenant Configuration Management（セキュリティベースラインの継続監視）、Secure Tenant Creation（テナント作成の統制と自動的な統制関係の確立）の4機能が提供される。

### 3. Copilot Credit の従量支出に M365 管理センターのコスト管理が付いた — 対象は Cowork と Work IQ から

**要点**: 管理者が、従量課金型サービスの Copilot Credit 消費を管理センターで監視・制御できるようになった。従量利用の支出は「使い切ってからエンフォースメントで気づく」ものではなく、事前に上限とアラートを置ける対象へ変わる。

**詳細**: 初期の対象は **Cowork と Work IQ**。今回の更新では、支出アラートの信頼性向上、ユーザー単位のオーバレージ処理の強化、各管理センター間での前払い容量の見え方の整理が行われた。⚠️ **1人のユーザーが複数のポリシーに属する場合は「ユーザー単位の上限が最も高いもの」が適用され**、次いでポリシーの上限が大きいもの、さらに作成日が新しいものの順で決まる。

あわせて **Agent 365 ダッシュボードが GA** し、組織全体のエージェント導入状況をアクティブユーザー・リテンション推移・利用の多いエージェント・エンゲージメントの観点でドリルダウンできるようになった。

- https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-agent-365-%E2%80%93-july-2026/4543654
