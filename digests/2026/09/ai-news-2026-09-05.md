### 2. SharePoint の「AI 向け HTML ガイダンス」が全テナントに開放された — 生成 HTML の作り直しが不要になる

**要点**: 全 Microsoft 365 顧客のテナントに `_html` というテナント固有のガイダンスページが用意された。Cowork / Scout / GitHub Copilot / Copilot Studio にこの URL を渡すと SharePoint のサンドボックスで動く HTML を生成でき、SharePoint リストにライブ連結したレポートも作れる。前提は「AI が出す HTML は SharePoint で動かないので人が直す」から「URL を1本渡す」へ移った。

**詳細**: 一次は SharePoint Blog の月次「What's New in Copilot in SharePoint: September 2026」（**9/2 23:26Z** 公開・掲載歴ゼロ）。記事はガイダンスの所在を `https://[tenantname].sharepoint.com/_html` と示し、テナントで新しい機能が使えるようになると内容が自動更新されるとしている。狙いは「AI アシスタントは標準的な Web HTML を生成するが、それが SharePoint で期待どおり動くとは限らない」点の解消で、SharePoint の要件を毎回説明する手間をなくすことにある。同記事は他に3系統を挙げる。

- 個人スキルがサイトをまたぐ: 1度作った個人スキルを全 SharePoint サイトで使える。書式・基準・繰り返しの手順が1サイトに縛られなくなる
- スキルを評価で改善する: 手で指示文を書き直す代わりに、Copilot にテストと評価基準の作成・測定付きの修正提案までを依頼できる
- 画像の横断理解: ライブラリ内の画像を1枚ずつ開かずに、機器やラベルの特定と可視テキストの抽出をまとめて依頼できる
- ワークフロー2種: ファイル追加・メタデータ更新を契機に Teams のチャット／チャネルへ投稿する通知と、ファイルやリストの文脈に紐づけたまま回す承認ルーティング

利用条件は **Microsoft 365 Copilot ライセンス**で、管理者の追加設定は記載されていない。

- https://techcommunity.microsoft.com/t5/microsoft-sharepoint-blog/what-s-new-in-copilot-in-sharepoint-september-2026/ba-p/4535422
