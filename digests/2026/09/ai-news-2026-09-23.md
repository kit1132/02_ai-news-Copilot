### 1. [予定] M365 Copilot の推論を国内で実行する計画が Roadmap に載った — 主権対応の争点が「保存場所」から「推論場所」へ動く

- 提供開始地域: オーストラリア / インド / アラブ首長国連邦 / 英国 / 米国の**5か国**
- 状態: `In development`。GA 期日 **December CY2026**（Preview 期日の記載なし）
- 対象範囲: 「supported Copilot interactions」とあり、どのやり取りが対象かは一次に内訳がない
- 既存の枠組みとの関係: これまでの Advanced Data Residency / Multi-Geo は**保存時（at rest）**のコミットメントで、推論の実行場所は対象外だった

⚠️ **9/21 に掲載した SpaceXAI サブプロセッサは「在国内処理（in-country processing）のコミットメントから除外される」と明記されている。**モデルごとに在地推論の可否が割れる構造になるため、地域要件のあるテナントでモデル選択を設計する場合、モデル可用性の表だけでなく在地推論の対象かどうかを別軸で確認する必要が出る。

### 3. [仕様] 情報バリアを有効にしたテナントでは Cowork プラグインを配布できない — 規制業種での拡張が「設定次第」ではなく塞がっている

**要点**: Microsoft Purview 情報バリア（IB）が有効なテナントでは、埋め込みナレッジのファイルアップロードが**テナント単位で遮断**され、該当するプラグインとスキルを公開できない。IB 運用下では Cowork 拡張の計画そのものが成り立たない。

**詳細**: `cowork/cowork-plugin-development` の `ms.date` が **2026-09-17 → 2026-09-21** へ動き、`updated_at` も 2026-09-21T22:35Z へ更新された。9/19 に本ページを初検知して取り込み経路と各種上限を掲載したが、以下の統制条項には触れていなかった。⚠️ **9/19 時点の本文にあったのか 9/21 の改訂で入ったのかは一次から確定できない**（改訂差分を取る手段がないため。B-076 起票）。

- IB の非対応: 「Microsoft Purview Information Barriers (IB) aren't currently supported for plugin or skill management and sharing」と明記され、IB が有効なテナントでは埋め込みナレッジのファイルアップロードがテナントレベルでブロックされる
- ISV コンテンツの非索引化: Microsoft は ISV コンテンツを含む永続的な索引・ナレッジグラフ（**Microsoft Graph を含む**）・データベースを、クロール／スクレイピング／一括エクスポート／API・MCP 経由のいずれの方法でも作成・維持しない。リアルタイム応答のため一時的に処理することはあるが、そのセッションを超えて保持しない。ISV が書面で要求した場合は **10営業日以内**に削除し、書面で証明する
- MCP 注釈による確認要求: `readOnlyHint` が `false` か `destructiveHint` が `true` のツールは実行前にユーザー確認が入る。⚠️ **注釈の無いツールは破壊的として扱われ確認対象になる**ため、全ツールに安全性注釈を付ける必要がある
- ワークスペースのファイル入力: パラメーターを `contentEncoding: base64` で宣言すると、Cowork が利用者のファイルを解決して base64 化してから呼び出す。1回のツール呼び出しで **8ファイル / 150 MiB** まで、配列型のファイルパラメーターは1ツールに1つまで
- Microsoft ツールの扱い: Graph・Dataverse 等の Microsoft 製ツールは注釈にかかわらず Cowork 内蔵ポリシーで制御される

- https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development
