前日 10/14 からの差分。68日間ゲートウェイ拒否が続いていた mc.merill.net が今日は取得でき、未掲載の Message Center 通知がまとめて見つかった。そのうち3件をハイライトにした（Copilot Studio のモデル退役、App Builder / vibe.powerapps.com の退役、Entra のエージェント作成権限の既定変更）。Learn では、Copilot Studio 標準ハーネスの既定モデルが「GPT Chat Latest」に変わった。GitHub Copilot ハーネスの接続エージェントは Foundry・A2A・Agents SDK に広がった。Roadmap には 10/13 23:01Z に17件のバッチが入り、そのうち Work IQ が5件だった。

## 今日のハイライト

### 1. [廃止] Copilot Studio の GPT-4.1 / GPT-5 系が 11/12 に退役する — 既定モデルが特定版から「最新版に追従する別名」に変わる

**要点**: MC1506318 によると、標準ハーネスの GPT-4.1・GPT-4.1 Mini・GPT-5 Chat / Auto / Reasoning は、**11/12** に「GPT Chat Latest」へ自動移行する。既定モデルは、決まった版から、同じメジャー版の中で更新され続ける別名に変わる。

**詳細**: 通知は 10/13 公開・10/14 更新で、タグは Retirement。Learn の `authoring-select-agent-model` も 10/14 01:04Z に改訂された（`8c4bcb69`・`ms.date` 10/13）。全13リージョンで Default が GPT-5.5 Chat から **GPT Chat Latest** に入れ替わっている。

- 移行先: 標準ハーネスはすべて GPT Chat Latest に移る。GitHub Copilot ハーネスでは、GPT-5 Chat が GPT 5.6 Terra に、GPT 5.6 Sol / Luna がそれぞれ GPT 6 Sol / Luna に移る
- 例外: 米国外でリージョンをまたぐデータ移動を制限している環境では、GPT-4.1 と GPT-5 は退役しない
- GPT Chat Latest の扱い: 同じメジャー版の中のスナップショット更新は自動で反映される。メジャー版が上がるときは **30日以上前**に告知される
- 影響を受けるエージェントの探し方: PPAC の Manage > Copilot Studio で、エージェントをハーネスとモデルごとに確認できる。ただしモデル欄はプレビューで、公開済みの構成しか反映されない
- 続報: Claude Opus / Sonnet の旧版の退役日は別途告知される。モデル表では、標準ハーネスの実験枠が Grok 4.1 Fast から **Grok 4.2**（Deep・米国の早期アクセス環境のみ）に替わった。一方で、Important 注記は Grok-4.1 Fast を名指ししたままである

- https://mc.merill.net/message/MC1506318
- https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-select-agent-model

### 2. [廃止] App Builder エージェントと vibe.powerapps.com が 11/30 に退役する — 10月中旬から新しいアプリは作れない

**要点**: MC1505609 によると、M365 Copilot の App Builder エージェントと vibe.powerapps.com は **11/30** に退役し、10月中旬から新規作成ができなくなる。自然言語でアプリを作る入口は、Copilot Cowork と Copilot Studio の2つにまとめられる。

**詳細**: 10/12 公開で、Act by は 11/30 である。移行しなかったアプリは、11/30 以降は退役した画面から開けなくなる。

- 日程: 10月中旬に製品内の移行機能が提供され、同時に新規作成が止まる。11/30 に退役する
- 移行先: Cowork のアプリは 9/8 から Frontier で提供されている。Copilot Studio のアプリは10月上旬からパブリックプレビューで展開中である（既報 MC1469329）
- 管理者に求められる対応: 利用している作成者を特定し、日程を伝える。残したいアプリは 11/30 までに移行を終える

- https://mc.merill.net/message/MC1505609

### 3. [破壊的変更] Entra で一般ユーザーがエージェントのブループリントを作れるようになる — 11/4 から既定でオン

**要点**: MC1506733 によると、**11/4** から、Entra のロールを持たない一般ユーザーもエージェントのブループリントを作成できるようになる。止めたいテナントは、展開前に「Users can create agent blueprints」をオフにする必要がある。

**詳細**: 10/13 公開。展開は11月上旬に始まり、11月下旬に完了する。

- 設定場所: Entra 管理センターの Entra ID > Users > User settings > Default user role permissions。トグルは今変更しておくことができ、展開の開始時に有効になる
- 影響しない範囲: 既存のブループリント、既存のブループリントからエージェント ID を作れる人、Foundry や Security Copilot 側の作成要件には影響しない。「Users can register applications」とも別の設定である
- 関連（MC1506728・同日）: 11/4 から、ブループリントには `AgentIdentity.CreateAsManager` 権限が自動では付与されなくなる。エージェントが ID を作るには、管理者の同意が必要になる

- https://mc.merill.net/message/MC1506733
- https://mc.merill.net/message/MC1506728
