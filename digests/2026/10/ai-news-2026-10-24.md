## 今日のハイライト

### 1. [廃止] AI Builder の容量アドオンが 11/1 に販売終了になる — 自動更新を切らないと退役済みアドオンが更新されてしまう

**要点**: Partner Center の 10/22 付アナウンスによると、AI Builder の容量アドオンは 11/1 から販売されなくなる。既存の契約は期間の終わりまで使えるが、その後の AI Builder 機能は Copilot Credits で賄う前提に変わる。CSP パートナーは各顧客の次回更新日より前に自動更新を切る必要がある。

**詳細**:
- 対象: AI Builder の容量アドオンを使う顧客を持つ CSP ディストリビューター・直接課金パートナー・間接リセラー
- 既存契約: 有効なサブスクリプションの AI Builder クレジットは、現在の契約期間の終わりまで使える
- パートナーの作業: 直接課金パートナーと間接プロバイダーは Partner Center で自動更新を切る。間接リセラーはディストリビューターと調整する
- 移行先: 既存クレジットが切れた後も AI Builder 機能を使い続ける顧客は Copilot Credits で計画するよう案内している
- 同じ日付の MAICPP 月次更新では、Custom Solutions for Microsoft Teams スペシャライゼーションが 11月に退役し、MS-102 の退役（11/30）に合わせて AB-650 が Modern Work の要件に加わる

- https://learn.microsoft.com/en-us/partner-center/announcements/2026-october

### 2. [破壊的変更] Copilot コネクタの統制が 10/30 から Agent 365 の Allowed agent types 設定に従う — CLI の setFederatedConnectors は使われなくなる

**要点**: MC1454973 の 10/23 改訂版によると、10/30 から全テナントで Copilot Connectors ページが、M365 管理センターの Agent 365 にある Allowed agent types 設定に従って動く。これまで CLI の `setFederatedConnectors` でコネクタを統制していた組織は、6日以内に Allowed agent types の設定を見直す必要がある。

**詳細**:
- 日程: `setFederatedConnectors` の CLI トグルは 8/25 までに非推奨になった。10/30 から Copilot Connectors ページが Allowed agent types の構成を強制する
- 何もしない場合: テナントは Allowed agent types の既存の構成と既定の姿勢で統制される。意図した統制と合うかを確かめるよう求めている
- 管理者の作業: CLI トグルに依存するスクリプト・自動化を移す。M365 管理センター > Agent 365 > Allowed agent types の構成を 10/30 より前に検証する
- 経緯: 8/14 公開の v1 から、10/23 の v2 で日程が改められた（タグは Retirement / Admin impact）。CLI トグルを使っていない組織は対応不要

- https://mc.merill.net/message/MC1454973

### 3. [新機能] Copilot のクレジット支出ポリシーと残高を Microsoft Graph から操作できるようになる — 管理センターの手作業から FinOps 自動化へ

**要点**: MC1521616 によると、管理者と開発者は Microsoft Graph の beta エンドポイントで、Copilot Credits の支出ポリシーの作成・更新・削除、残高の取得、利用者からの追加クレジット申請の承認・却下をできるようになる。10月中旬からパブリックプレビューで展開し、従量課金の統制を既存の管理・FinOps の仕組みに組み込めるようになる。

**詳細**:
- 操作できるもの: テナント・ユーザー・サービス単位のクレジット残高の取得、支出ポリシーの CRUD、ポリシーへのセキュリティグループ割り当て、サービス別の設定、メールのしきい値アラート、クレジット申請の取得・承認・却下
- 含まれないもの: 詳細な消費レポート。GA 日は未定
- 準備: Graph の権限と認証の要件、ポリシーに割り当てるセキュリティグループ、アラートの受信者を決める。使わない組織は対応不要

- https://mc.merill.net/message/MC1521616
