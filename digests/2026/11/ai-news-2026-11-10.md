## 今日のハイライト

### 1. [新機能] Copilot コネクタの書き込み操作が Copilot Chat と Cowork で GA になった — Copilot から外部システムへ書き戻すことが、既定の機能になった

**要点**: 利用者は Copilot Chat と Cowork で、MCP ベースの Copilot コネクタ（フェデレーテッドコネクタ）を通じて、接続先のデータを会話から作成・更新・削除できるようになった。書き込みツールは既定で「Needs approval」になっている。利用者が「Always allow」を選ぶと、そのツールは確認なしで動くようになる。

**詳細**: TC の Microsoft Copilot Blog（11/9 20:51Z）。Office アプリの Copilot は「近日対応」である。Learn の `federated-connectors-overview`（`ms.date` 10/19・10/28 14:54Z `ef44b720`）には承認の仕組みが先に載っていた。
- 承認の選択肢: Allow once / Allow for conversation / Always allow / Cancel。許可はコネクタ全体ではなくツール単位でかかる。発行元がツールを足したり変えたりすると、そのツールは Needs approval に戻る
- 読み取りツール: 常に許可で、承認は求められない。設定の場所は Copilot の Settings > Sources > Tools
- 実行の範囲: 利用者本人の権限で接続先のサービスに対して実行し、データは M365 に索引されない。確認待ちのあいだは何も送られない。Researcher では読み取り専用のままである
- 管理者: M365 管理センターで MCP ベースのコネクタごとに、作成・更新・削除ができるツールを確かめられる。操作は Purview で監査できる
- 記事が挙げる接続先: Atlassian Rovo（Jira / Confluence）・Notion・Canva・G2・iManage・BioRender
- https://techcommunity.microsoft.com/t5/microsoft-copilot-blog/turn-copilot-insights-into-action-with-connector-write/ba-p/4571160
- https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/federated-connectors-overview

### 2. [新機能] 管理者が Power Pages の認証方式を、プロトコル・ID プロバイダー単位でサイトごとに禁止できるようになった（preview） — 外部認証を丸ごと許可するか禁止するかの二択ではなくなった

**要点**: 管理者は PPAC で、OpenID Connect・SAML 2.0・WS-Federation・OAuth 2.0 の各プロトコル、Google・Microsoft・Facebook の各 ID プロバイダー、ローカル認証を個別に許可・禁止できるようになった（パブリックプレビュー）。禁止は、その方式を既に使っているサイトにも効き、利用者はその方式でサインインできなくなる。

**詳細**: Power Platform Blog（11/9 15:54Z）。これまでは外部認証全体の許可・禁止しかできなかった。
- 設定の場所: PPAC の Manage > Products > Power Pages > Settings > Authentication。環境を選び、許可するサイトを指定する。Power Platform 管理者か Dynamics 365 管理者のロールが要る
- サイトの指定: 環境全体で禁止したうえで、特定のサイトだけ許可できる（例: パートナー向けポータルだけ SAML 2.0 を許可する）
- 既定: すべての方式が許可されている。許可は「メーカーが構成できる」状態にするだけで、認証を有効にするわけではない
- 確定の前: 管理センターが影響を受けるサイトを一覧にして、稼働中のサイトへの影響を警告する。サイトの所有者と管理者には、適用時と変更時にメールが届く
- メーカー側: 禁止された方式はデザインスタジオでグレーアウトし、管理者が無効にした旨が表示される
- https://www.microsoft.com/en-us/power-platform/blog/power-pages/new-authentication-governance-controls-in-power-pages/
