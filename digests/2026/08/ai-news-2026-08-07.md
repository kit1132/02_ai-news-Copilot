### 1. Copilot in SharePoint がリストから「開くたびに更新される」ダッシュボードを作る — 一覧の可視化に別ツールを立てる前提が動く

**要点**: SharePoint リストから、元データにつながったままの対話型 HTML レポートを Copilot が生成できるようになった。リストの可視化は Power BI なり Power Apps なりを別に立てて接続する前提だったが、リスト所有者がチャットだけで完結させる側へ寄った。

**詳細**: 8/6 公開の月次記事「What's New in Copilot in SharePoint: August 2026」（記事ID 4535421）で3件が案内された。board RSS 経由で本文を一次取得している。

- ライブ SharePoint ダッシュボード: リストから対話型 HTML レポートを生成する。静的な出力ではなく元データに接続したままで、記事は「Your SharePoint dashboard refreshes from the list whenever it's opened」と書いている。用途としてプロジェクト状況の追跡・在庫管理・採用の3つを挙げている
- ページのボタンからのプロンプト起動: SharePoint ページに任意のボタンを置き、特定の Copilot プロンプトをワンクリックで実行できる。利用者に複雑な指示を覚えさせずに済ませることを狙いとしている
- チャット体験の改善3点: `/` でファイル・人・会議を検索して差し込める、スキル作成のカード体験が滑らかになった、チャット UI がコンパクトになり引用カードが改善された
- 利用条件は **M365 Copilot ライセンス**の保有で、記事は導入支援リソースとプロンプトライブラリへ誘導している
- ⚠️ 提供段階（Preview / GA / 展開中）は記事に明示されていない。Learn 側の Copilot in SharePoint は現時点でも preview 版として記述されている

- https://techcommunity.microsoft.com/t5/microsoft-sharepoint-blog/what-s-new-in-copilot-in-sharepoint-august-2026/ba-p/4535421
- https://learn.microsoft.com/sharepoint/copilot-in-sharepoint-skills

### 2. Work IQ Developer Tools が開発者プレビューに入った — Copilot プラグイン開発が工程ごとの継ぎはぎから1本のツールに変わる

**要点**: Microsoft は、Copilot プラグインの作成から公開・監視までを1つの CLI とエージェントプラグインに束ねた WIQD を開発者プレビューで出した。拡張開発は工程ごとに別ツールを繋ぐ前提だったが、一連をエージェントに丸ごと渡して回せる面に変わる。

**詳細**: 8/6 に Microsoft 365 Developer Blog で公開された。対象はスキル・コネクタ・宣言型エージェントを含むプラグイン全般で、記事は工程を create → configure → validate → provision → package → share → ask → eval → publish → monitor の一続きとして示している。

- CLI: Windows は PowerShell、Mac / Linux は bash でインストールする。`wiqd agent eval init`・`wiqd agent eval`・`wiqd feedback`・`wiqd agent monitor` などのコマンドを持つ
- エージェントプラグイン: Copilot と IDE のチャットの中にライフサイクル全体を露出させる
- Language Server（LSP）: プラグインファイルの診断をライブで返す
- VS Code 拡張: 上記を IDE 側から使えるようにする
- 前提は Node.js と、Copilot ライセンス付きの M365 テナント。対応面は Copilot チャット / IDE チャット / ターミナル / VS Code / CI/CD パイプライン
- ⚠️ 土台の Work IQ CLI（`@microsoft/workiq`）については、Learn 側に **2026-06-16 に GA** したこと、`0.4.x` / `0.5.x` などの旧プレビュー版はサポート対象外であることが明記されている。**実行には Copilot Studio 側で Azure サブスクリプションとリソースグループを割り当てた使用量ベース課金プラン**（Copilot Credits）と、Entra テナントでの Work IQ アプリへの管理者同意が必要で、開発者が個人の判断だけでは動かせない
- 導入経路は GitHub Copilot CLI のプラグイン（`/plugin install workiq@copilot-plugins`）、`npm install -g @microsoft/workiq`、`npx -y @microsoft/workiq mcp`、VS Code の MCP サーバー登録の4種類

- https://devblogs.microsoft.com/microsoft365dev/announcing-the-preview-of-the-work-iq-developer-tools/
- https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/workiq-overview
