**詳細**: `copilot/manage/app-builder-migration`（`ms.date` 11/3・11/4 18:33Z `705972b6`）。App Builder の退役（11/30）そのものは既報。
- ワンクリック移行: App Builder でアプリを編集できる人（通常は作成者）だけが使える。画面・ナビゲーション・ロジックはソースコードから移る。SharePoint リストのデータはそのままで、接続は自動でつなぎ直される
- 手動移行: ソースコードの .zip をダウンロードし、移行用のプロンプトに添付して Cowork か Copilot Studio の Apps で作り直す。こちらは今すぐ使える
- 移行後の作業: 新しいアプリを公開し、元のアプリを使っていた人にあらためて共有する。元のアプリは 11/30 まで変わらず残る
- Cowork の App スキルは Frontier に参加しているテナントだけで使える。アプリの作成と実行は Copilot Credits を消費する（実行が Power Apps Premium ライセンスの要求上限内に収まる場合を除く）

### 2. [仕様] Copilot の Claude モデルの一部は、Anthropic がデータを保持し Microsoft の DPA が適用されない — Copilot の Claude はすべて Microsoft の DPA の内側、という前提は成り立たない

**要点**: Claude Fable 5 や Claude Mythos 5 などの「Anthropic models with Data Retention」は、管理者が M365 管理センターで明示的に opt-in しない限り誰も使えない。opt-in すると Anthropic は独立した処理者になり、入出力の大半を最長30日保持する。ここには Microsoft の Product Terms と DPA が適用されない。

**詳細**: `copilot/implement/connect-to-ai-subprocessor`（`ms.date` 11/4・11/4 21:31Z `a6af92b4`。改訂の差分は特定できていない）。
- Fable 級のモデル: 対象になる組織では、Fable 5.1 は Anthropic をサブプロセッサーとして提供され、Microsoft の DPA が適用される。Anthropic は顧客コンテンツを保持しない。サブプロセッサーの設定で Claude を有効にしていれば、追加の opt-in は要らない
- データ保持つきのモデル: 商用クラウドで Claude が既定オンの地域でも、すべてのシナリオで既定オフになっている。使うには Anthropic の Commercial Terms of Service と DPA への同意が要る。管理者は使える利用者を全員か、特定のユーザー・グループから選ぶ
- 保持の期間: 入出力の大半は最長30日。Anthropic の利用ポリシー違反の疑いがあると、コンテンツは最長2年、分類スコアは最長7年保持される。明示の許可なくモデルの学習には使わない
- 利用者の見え方: 製品の中で、そのモデルが Anthropic のデータ保持を要すると分かる表示が出る
- https://learn.microsoft.com/en-us/copilot/implement/connect-to-ai-subprocessor

### 3. [新機能] 管理者が、メーカーの資格情報を埋め込んだエージェントの共有を環境ごとに止められるようになった — 「作った人の権限で動くエージェントを配る」設計は、PPAC の設定ひとつで新規の共有と公開が止まる

**要点**: 管理者は PPAC の環境設定「Sharing agents with embedded maker credentials」で、メーカーへの警告だけにするか（All sharing allowed）、安全でないエージェントの新規共有と公開を止めるか（Safe sharing enforced）を選べるようになった。Roadmap 566873（GA 期日 September CY2026・In development のまま）が告げていた統制が Learn に載った。

**詳細**: `microsoft-copilot-studio/configure-sharing-agents-embedded-maker-credentials`（`ms.date` 11/3・11/4 01:04Z `c86e09f0`）。ページに preview の表記はない。
- 安全でないと判定される条件: 資格情報の共有を許さない接続を1つ以上使い、その接続がデザイン時に入れた資格情報を使っていること。呼び出すフローやエージェントの依存関係も判定に含まれ、対象は今後広がる
- 止まるもの: Safe sharing enforced では、編集と保存はできるが新規の共有ができない。共有の操作がないチャネルでは公開が止まる。既に共有したエージェントも、再公開のときに止まることがある
- 止まらないもの: 実行中のエージェントは止めない。既存の共有をさかのぼって解除することもない
- 回避の方法: 利用者ごとの認証に切り替えるか、サービスプリンシパル・API キー・マネージド ID などの承認されたシステム ID に置き換える
- 設定の場所: PPAC の Manage > Environments > Settings > Features。環境ごとに設定する
- https://learn.microsoft.com/en-us/microsoft-copilot-studio/configure-sharing-agents-embedded-maker-credentials
