## 今日のハイライト

### 1. [予定] Copilot の Claude モデルが2026年末までに EU Data Boundary の内側で処理されるようになる — EU / EFTA の組織は「Claude を使う」か「域内処理の約束を守る」かを選ばなくてよくなる

**要点**: EU / EFTA の組織は、2026年末までに、Cowork を含む Copilot の各体験で Claude モデルを EU Data Boundary の内側の処理で使えるようになる。これまで Learn は Anthropic モデルを EU Data Boundary の対象外と書いており、Claude を有効にするには域外処理を受け入れる必要があった。

**詳細**: Copilot ブログ 11/5「Bringing Claude models in Microsoft Copilot into the EU Data Boundary」（Charles Lamanna 名義）。提供日はまだ示されていない。
- 既に Claude を使っている組織: 何もしなくてよい。提供が始まると、処理は自動で EU Data Boundary の内側に移る
- まだ有効にしていない組織: EU / EFTA では設定の既定は無効。管理者は M365 管理センターで、全ユーザーにも、選んだユーザー・グループだけにも有効にできる
- 対象の体験: Chat、M365 アプリの Copilot、Copilot Cowork、Copilot Code
- 関連する Learn の改訂: `cowork-models` と `cowork-admin-governance`（11/5 改訂）は「Anthropic の有効化はユーザー・グループ単位で範囲を絞れる」と書いた。一方、同じ日に改訂された `cowork-access` は「モデルの設定はテナント全体で、一部のユーザーにだけモデルを与えることはできない」のままで、ページ間で記述が食い違っている。`cowork-models` の「EU Data Boundary の中では GPT モデルだけが使える」という注記も残っている
- https://www.microsoft.com/en-us/copilot/blog/2026/11/05/bringing-claude-models-in-microsoft-copilot-into-the-eu-data-boundary/
- https://learn.microsoft.com/en-us/copilot/cowork/cowork-models

### 2. [新機能] M365 管理センターにエージェント利用状況レポートと Copilot Search の権威あるコンテンツ管理が加わった — 管理者がエージェントの利用と検索の順位を管理センターから扱えるようになった

**要点**: 管理者は、M365 管理センターで、ライセンスの有無と発行元の種類別にエージェントの利用状況を見られるようになった。また、Copilot Search で上位に出す SharePoint サイトを最大100件まで指定できる。Release Notes の新バッチ（10/28〜11/3 リリース分・10項目）に含まれる。

**詳細**: M365 Copilot Release Notes「November 4, 2026」（ページ改訂 11/5 03:32Z・`e9994cf6`）。
- エージェント利用状況レポート（Roadmap 497999）: 対象は M365 Copilot と Copilot Chat のエージェント。アクティブなエージェント利用者数とアクティブなエージェント数を、ライセンスあり・なし別、発行元（ユーザー作成・自社・Microsoft・パートナー）別に分ける。利用者単位、エージェント単位、利用者とエージェントの組み合わせ単位の詳細も出る
- 権威あるコンテンツ（Roadmap 503553）: Copilot > Search > Authoritative content に置かれる。Global admin と Global reader が閲覧・追加・削除と一括インポート・エクスポートを行える。上限は SharePoint サイト100件
- 同じバッチの残り8項目はカテゴリ別まとめを参照
- https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes

### 3. [予定] GPT-6 Astra と Claude Fable 5.1 を Chat と Word / Excel / PowerPoint で使う UBB モデルの GA が12月上旬に延びた — 11月中に全社で使い始める前提は崩れた

**要点**: Copilot アプリの Chat と Word / Excel / PowerPoint のモデル選択で、従量課金（UBB）のモデルとして GPT-6 Astra と Claude Fable 5.1 を使える時期が変わった。GA は11月上旬〜中旬から、12月上旬開始・12月中旬完了に移った。Frontier の展開は11月上旬〜中旬のままで、Chat では推論の強さも選べるようになる。

**詳細**: MC1519122（10/21 公開・11/4 更新・Roadmap 571400）。
- 前提: 利用者に M365 Copilot のユーザーライセンス（USL）があり、テナントで UBB が有効になっていること。UBB が無効なら UBB モデルは出ない
- 管理者への影響: M365 管理センターの Agent 365 コスト管理で、UBB の有効化と Credits の割り当てが必要になる。利用者が管理者に Credits の追加を求める機能は、最初の展開の後に出る
- https://mc.merill.net/message/MC1519122
