### 1. 業務用 Copilot の Web URL が 8/18 から copilot.cloud.microsoft へ移る — 許可リストの確認期限は3日後

**要点**: 業務用 Copilot の Web URL が `m365.cloud.microsoft` から `copilot.cloud.microsoft` へ移り、自動リダイレクトが 8/18 に始まる。前提が「新旧どちらの URL でも届く」から「新 URL をブロックしている組織は自動リダイレクトが効かない」へ変わるため、ネットワーク側の確認が先に要る。

**詳細**: Partner Center の8月アナウンスに **8/14 付**で追記された。2026-08-18 から Web・デスクトップ・モバイルの Microsoft Copilot アプリが更新され、職場アカウントと個人アカウントを見分けやすくする変更が入る。

- アカウント表示: アカウントラベル、Microsoft Entra 職場アカウントを示す緑の盾、背景の描き分けが追加される
- 名称とアイコン: 「Microsoft Copilot」に簡素化される
- Web の URL: `m365.cloud.microsoft` から `copilot.cloud.microsoft` へ移り、自動でリダイレクトされる。ただし組織側で新 URL へのアクセスがブロックされている場合は**リダイレクトされない**

パートナーに求められている確認作業は、`copilot.cloud.microsoft` が既存のネットワーク・プロキシ・ファイアウォール・アクセスポリシーでブロックされていないこと、`*.cloud.microsoft` を許可リストに追加すること、URL 移行に向けた接続性の検証の3点である。Windows / Mac デスクトップアプリは **8/18 に早期プレビュー**、広範な展開は**9月中旬**から始まる。セキュリティ・コンプライアンス・ガバナンスの制御は変更されない。

⚠️ 8/22 に予定されている「M365 Copilot アプリのチャット中心 UI」の Deferred リング展開（**MC1325422**）とは別の変更である。あちらは画面構成、こちらはアプリの統合と URL の移設で、8月後半に2つが重なる。

- https://learn.microsoft.com/en-us/partner-center/announcements/2026-august

### 2. Copilot Agent Kit August 2026 が出た — ハーネス製エージェントがようやく棚卸しツールの対象に入った

**要点**: Power CAT のキットが約5週間ぶりに更新され、Agent Review Tool が **GitHub Copilot ハーネス**製エージェントに対応した。8/3 の GA 以降「ハーネスで作ったエージェントは既存のガバナンスツールの外にある」状態だったが、レビューと変更追跡の対象に入った。

**詳細**: 2026-08-14 公開（タグ `CopilotStudioAccelerator-August2026`）。目玉は **Agent Change Tracker** で、エージェントの変更を継続的に追跡し、バージョン付きのタイムラインと変更したメーカーの情報を残す。誰がいつ何を変えたかを後から辿れるようになる。

- Agent Review Tool: GitHub Copilot ハーネスを使うエージェントをレビュー対象にできる
- Agent Library: MCP Apps ギャラリーが追加され、Skills と Automations をアップロードできる
- Agent Inventory Settings: 検出と監視の設定を構成できる。メタデータ抽出が多言語に対応した
- Bulk Actions: モデル駆動アプリからエージェントを一括で検疫できる
- Agent Value Summary: 日次スキャンを最適化し AI クレジットの消費を抑えた
- Agent Debugger は新しいエージェント種別に対応し、テスト自動化はアダプティブカードの応答を扱えるようになった

⚠️ Copilot Studio の What's New は同じハーネスをいまも `(Production-ready preview)` と書いており、**GA から12日連続の未反映**である（B-023）。一次ドキュメントより先に、周辺ツール側が GA に追いついた形である。

- https://github.com/microsoft/Power-CAT-Copilot-Studio-Kit/releases

### 3. Low Code App Development と Intelligent Automation のスペシャライゼーションが統合された — Copilot Studio の実績だけでも到達できる

**要点**: 両スペシャライゼーションが 2026-07-31 付で **Agentic Business Solutions** に統合され、性能要件に「Copilot Studio の新規顧客導入2件・各 $10,000 TTM 以上」という経路が加わった。前提が「Power Apps と Power Automate の本番導入実績が必須」から「Copilot Studio 実績だけでも到達できる」へ変わる。

**詳細**: Partner Center の月次 MAICPP アップデート（8/13 付）で判明した。既存の登録パートナーは同じ更新日で新スペシャライゼーションへ自動的に移されている。性能要件は次の二者択一になった。

- 経路1: 新規導入の顧客2社。うち1社は Power Automate のフローが本番稼働、もう1社は Power Apps アプリを最低5ユーザーで本番稼働（関連付けは PAL）
- 経路2: **Copilot Studio 新規導入2社**・各 **$10,000 TTM** 以上（非経常。関連付けは CPOR / CSP T1 / CSP T2 / CSPCPOR）

スキル要件も積み増された。Power Platform Functional Consultant Associate・Intelligent App Builder・AI Agent Builder Associate のいずれかを5名以上、Power Platform Developer Associate または Power Automate RPA Developer Associate を2名以上、**Agentic AI Business Solutions Architect** を2名以上が必要になる。あわせて Power Apps / Power Automate / Copilot Studio / Power Virtual Agents のコンサルティングサービスを Microsoft Marketplace に1件以上公開し、対象製品をタグ付けすることが条件に加わった。

⚠️ Frontier Partner バッジは **2027年6月末で廃止**される。FY27 中は要件を満たす限り使えるが、以降は取得時期にかかわらず使用できない。後継は Frontier Partner スペシャライゼーションで、FY27 中に Partner Center へ登場する予定である。

- https://learn.microsoft.com/en-us/partner-center/announcements/2026-august
