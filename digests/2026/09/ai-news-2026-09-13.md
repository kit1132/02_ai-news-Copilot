### 1. Copilot に Grok が載った — 選べるモデルが増えたのではなく、Microsoft の契約保護が外れる選択肢が増えた

**要点**: SpaceXAI の Grok が Frontier 経由で Word / Excel / PowerPoint の Copilot に追加された。一次が定義する SpaceXAI 経路には Product Terms も DPA もデータ所在地も著作権補償も適用されないため、有効化はモデル選択ではなく契約条件の切り替えとして判断することになる。

**詳細**: Tech Community の Microsoft Copilot Blog に **9/12 15:00Z** 付「Expanding model choice in Copilot with Grok」が出た。SpaceXAI は Microsoft の **Online Services Subprocessor List** に追加され、アクセスは**既定で無効の専用管理設定**で管理される。

- **提供範囲**: Microsoft Frontier Program 経由で **Word / Excel / PowerPoint** から開始する。Microsoft は「まず絞った範囲で出してフィードバックと利用実態を集め、他の Copilot 面へ広げる前に評価する」としている
- ⚠️ **プレビュー期間中、EU・EFTA・英国の Frontier 顧客は対象外**である
- **事前評価**: 提供前にテスト・安全性検証・Responsible AI レビューを通すと明記されている

契約面は一次 `connect-to-ai-models`（`updated_at` **2026-09-11T18:45Z**・`ms.date` 9/11）が書いている。SpaceXAI モデルは Microsoft の外でホストされ、Microsoft の管理環境と監査統制の外でデータが処理される。

- **適用されない**: Product Terms、Data Processing Addendum、データ所在地コミットメント、監査およびコンプライアンス要件、SLA、Customer Copyright Commitment
- **代わりに適用される**: xAI Enterprise Terms of Service と xAI Data Processing Addendum
- **有効化**: M365 管理センター > Copilot > Settings > View all > **AI providers for other large language models** で SpaceXAI を選び、法的条件に同意したうえでアクセスできるユーザー／グループを指定する。グローバル管理者ロールが必要で、反映に数時間かかる。無効化は同じ画面で **No users** を選ぶ（これも数時間かかる）
- **Copilot Studio 側の追加統制**: Power Platform 管理センターの「Allow external large language models (LLMs) for generative responses」で別途許可する

⚠️ **ただし一次は M365 アプリ経路について書いていない。**`connect-to-ai-models` は対象を「Copilot Studio in Microsoft 365」としか書かず、告知が挙げる Word / Excel / PowerPoint に同じ契約除外が掛かるかは明示されていない。`microsoft-365-copilot-app-admin-settings`（`updated_at` **2026-09-11T18:11Z**）にも SpaceXAI の設定行は無い。導入判断では、この面の差が一次で埋まるまで Copilot Studio 経路の記述で保守的に見積もるのが安全である（**B-065 起票**）。

### 2. Copilot Agent Kit の9月リリースが出ていた — GitHub Copilot ハーネスのエージェントがガバナンス対象に入った

**要点**: Power CAT が **9/8** に「Copilot Agent Kit September 2026」を公開していた（週次確認の期日が本日のため初検知）。Agent Inventory が **GitHub Copilot ハーネス**に対応し、8/3 GA 以降そのハーネスで作ったエージェントを棚卸しできなかった状態が解消する。

**詳細**: タグは `CopilotAgentKit-September2026`、公開は **2026-09-08 09:46Z**。前回把握の 8/17（`CopilotStudioAccelerator-August2026.1`）から1本進んだ。

- **Agent Inventory V2**: **Code App アーキテクチャ**で作り直され、性能と操作性が改善した。⚠️ **GitHub Copilot ハーネスのエージェントが棚卸し対象に加わった。**収集するメタデータも増え、**MCP List・接続されたエージェント・Agent Owner ID** を追えるようになった
- **Agent Review Tool**: バージョン履歴が入り、エージェントのバージョン間で評価結果を比較できるようになった
- **Agent Debugger**: セッションセレクター、トランスクリプトの高度なフィルター、**実行が最も遅いステップの特定**を備えた UI に刷新された
- **Agent Change Tracker**: 変更活動を分析する監査履歴アナリティクス（複数ビューと指標）が加わった
- **Advanced Testing**: Adaptive Card 応答の検証で **Contains** 演算子を使えるようになった
- **修正**: 20件。エージェントのメタデータ投入、日付形式の扱い、コネクタ参照の失敗、スキル使用時の低速化、Create File / Calendar MCP / Custom Skill 各評価の不一致など
