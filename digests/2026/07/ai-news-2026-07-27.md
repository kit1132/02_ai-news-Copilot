### 1. Claude Opus 5 が M365 Copilot と Copilot Studio のモデルセレクターに（7/24） — 外部モデル選択が最新世代に追いついた

**要点**: Microsoft が Opus 5 を Copilot の6サーフェスのモデルセレクターに投入した。Copilot Studio も対象に含まれる。

**詳細**: 7/24 の Microsoft 365 Copilot Blog（Tech Community）で告知。対象は Word / Excel / PowerPoint / Copilot Chat / Copilot Cowork / Copilot Studio の6つ。Opus 4.8 比でエージェント型コーディング・専門知識業務・長期推論を改善したとしている。ロールアウトはリージョンとテナント構成で差があり、Copilot Studio で Anthropic モデルを使う場合は Microsoft 365 管理センターでのオプトインが前提になる。learn.microsoft.com 側はまだ追随しておらず、Copilot Studio What's New は6月節のままで GA 表記の最新は Claude Sonnet 5 と GPT-5.5 Chat、M365 Copilot Release Notes の 7/15 バッチにも本件の記載はない。

**意味**: Copilot Studio 案件でのモデル選定は「ブログ告知済み・Learn 未反映」の段階にある。テナント側で Anthropic モデルのオプトインが済んでいるかどうかで、実機のモデルセレクターに出る選択肢が変わる。

- https://techcommunity.microsoft.com/blog/Microsoft365CopilotBlog/available-today-anthropic-claude-opus-5-in-microsoft-365-copilot/4540524
- https://learn.microsoft.com/en-us/microsoft-copilot-studio/whats-new （Learn 側は6月節のまま）

### 2. Microsoft 365 Admin agent が全管理者に GA（MC1436831・7/22） — テナント運用そのものが自然言語操作の対象になった

**要点**: 管理センターと Copilot Chat から自然言語でテナントを操作できる管理エージェントが GA になった。

**詳細**: Message Center 投稿は 7/22。対象は Microsoft Entra の組み込み管理者ロール全般で、Microsoft 365 管理センターと Microsoft 365 Copilot Chat の双方から同一エージェントを呼べる。用途は M365 サービスの探索・構成・トラブルシュート・ガバナンス・管理。既存のロールベースアクセス制御に従い、変更を伴う操作には管理者の承認を挟む。利用の制限と監視は管理センター側の設定で行う。

**意味**: 顧客テナントに「Copilot が管理操作まで実行する」構成が既定で入ってくる。ガバナンス設計では、エージェントの実行権限が呼び出した管理者ロールに紐づく点と、無効化・監視の設定場所が管理センターにある点が確認事項になる。

- https://mc.merill.net/ （MC1436831・7/22）
- https://m365admin.handsontek.net/microsoft-365-admin-agent-now-generally-available-admins/ （二次・本文照合）

### 3. SharePoint Copilot Apps が公開プレビュー（7/9） — Copilot の会話内に自作の対話型 UI を出せる

**要点**: SPFx で作った対話型 UI コンポーネントを Copilot キャンバス内に直接描画できるようになった。

**詳細**: 7/9 に M365 Developer Blog で公開プレビューを告知。SPFx 1.24 プレビューの一部で、フィルタ可能なデータグリッド、複数ステップのフォーム、チャート、KPI ダッシュボード、スケジューラ、承認パネルなどを会話から離れずに操作できる。開発ツール（Copilot Workbench）は 7/9 から利用可、エンドユーザー向けの全世界展開は 7/20 頃に完了見込み。プレビュー中の配布はテナント/組織スコープのみで、SharePoint ストア経由の配布と GA は 2026年秋の予定。描画先は現時点で Copilot UX に限られる。

**意味**: Copilot 上の業務アプリ提案で、アダプティブカードより自由度の高い UI を選べるようになる。ただし配布がテナント内限定で GA が秋のため、外販や複数顧客への横展開を前提にした提案には現時点では乗らない。

- https://devblogs.microsoft.com/microsoft365dev/sharepoint-copilot-apps-now-in-public-preview-from-intent-to-action-in-microsoft-365-copilot/
- https://learn.microsoft.com/en-us/sharepoint/dev/spfx/copilot/overview-copilot-apps
