## 今日のハイライト

### 1. [新機能] Copilot の「エージェント」画面が「プラグイン」画面に置き換わり、管理者は M365 管理センターで一元承認する — 配布単位がエージェント単体からプラグイン（スキル＋コネクタ＋エージェント）に変わる

**要点**: 利用者は Home（Chat / Cowork）・Code・Autopilot・Word / Excel / PowerPoint・SharePoint で、承認済みプラグインを共通の Plugins メニューから使えるようになった。既存の Agents ページは Plugins ページに置き換わる。配布と統制の単位がエージェントからプラグインに移る。

**詳細**: 一次は Tech Community の 9/30 記事（展開中）と、Learn `extensibility/plugins-overview`（`ms.date` **2026-09-30**・`f12c7f22`）である。

- 管理: M365 管理センターの Agent 365 体験で Agents > Tools から、Microsoft・自社開発・パートナーのプラグインを有効化・ブロックし、ユーザーやグループに割り当てる
- 中身: スキル（再利用できる指示）・コネクタ（データとサービスへの承認済みアクセス）・エージェントを1パッケージにまとめる。MCP サーバーの接続設定も含められる
- 規模: 公開時点で **100超**のプラグインがある（HubSpot / Linear / Atlassian / Asana / Canva / Notion / MongoDB / IDC 等）
- 今後: Copilot Studio・GitHub Copilot・Microsoft Foundry もレジストリの対象になる予定と書く
- 開発: Work IQ Developer Tools（WIQD）の `wiqd plugin` コマンドで作成・検証・パッケージ・公開する（public preview）。既存の Agent Plugins 形式は `wiqd plugin import` で取り込める
- Learn は「公開しただけでは使えない。レビュー・取得・割り当て・有効化・接続は経路ごとに別の手順」と明記する。既存の API プラグインは宣言型エージェントのアクションとして引き続きサポートされる

- https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/introducing-the-plugin-registry---one-place-to-discover-and-govern-plugins-for-m/4559682
- https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugins-overview
- https://devblogs.microsoft.com/microsoft365dev/bring-your-plugin-to-microsoft-copilot-with-wiqd/

### 2. [料金] 従量課金の対象に Teams Phone Agent と SharePoint / OneDrive の Advanced work が加わった — 支出ポリシーは既定で新サービスへ自動適用される

**要点**: 管理者が M365 管理センターの Cost management で統制する従量課金サービスが、3種から6種に増えた。支出ポリシーの Auto-apply new services は既定で有効なので、既存のポリシーは追加されたサービスにも設定変更なしで掛かる。

**詳細**: 一次は Learn `usage-based-billing-overview-copilot-credits`（`ms.date` **2026-09-30**・`updated_at` 9/30 17:46Z・`2f90943c`）である。9/26 に「Code と Managed Runtime を載せていない」と記録した食い違いのうち、Managed Runtime は解消した。

- 追加: Advanced work in SharePoint / Advanced work in OneDrive（どちらも Copilot ライセンス必須）・Copilot Managed Runtime・Teams Phone Agent
- 従来から: Cowork・Work IQ API
- Managed Runtime: 構築時の消費は作成した製品側のポリシーに従い、実行時の消費は M365 管理センターで別のポリシーと割り当てを設定できる
- 自動適用を止めたい場合は、ポリシーごとに Auto-apply new services をオフにする。Code は本日もこの一覧にない

- https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-overview-copilot-credits
