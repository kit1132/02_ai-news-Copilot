## 今日のハイライト

### 1. [廃止+料金] AI Builder クレジットが Copilot Credits に置き換わり、11/1 以降の新規・更新ライセンスには付かなくなる — AI Builder の実行費用を Copilot Credits で見込む必要が出てくる

**要点**: MC1526652 によると、11/1 以降に新しく買うか更新する Power Platform / Dynamics 365 のライセンスには、AI Builder クレジットが付かなくなる。AI Builder の機能は残るが、実行費用は Copilot Credits で賄う形になる。どちらのクレジットも残っていないと、アプリやフローの中の AI Builder の実行が止まる。

**詳細**: 10/26 公開で、対象は Power Apps と Power Automate、タグは Admin impact である。10/24 に掲載した Partner Center の告知はアドオンの販売終了だけを扱っていたが、今回の通知はライセンスに付属するクレジットまで範囲を広げた。
- 期日: 容量アドオンは 11/1 に提供終了になる。有効な契約のクレジットは契約が切れるまで使える。11/1 より前に購入・更新したライセンスに付属するクレジットも、その契約期間の終わりまで残る。切り替えの期限は契約ごとに異なり、11/1 で一律に切れるわけではない
- 消費の順序: AI Builder の機能は、まず AI Builder クレジットを使う。それが無いか使い切ると、Copilot Credits から自動で引かれる。両方とも無ければ、その実行はブロックされる
- 換算: AI Builder クレジットは Copilot Credits に自動では変換されない。消費レートは機能ごとに違い、一律の換算比は示されていない
- Copilot Studio の中の AI Builder 機能は、すでに Copilot Credits を使っている
- 推奨される対応: 容量アドオンと、クレジットが付属するライセンスの契約満了日を洗い出す。アドオンの自動更新は M365 管理センターかパートナー経由で止める
- https://mc.merill.net/message/MC1526652

### 2. [新機能] Power Apps のキャンバス Studio に作成エージェントがプレビューで入った — 使うと GitHub の課金と GitHub の規約が適用される

**要点**: メーカーは、キャンバス Studio の左レールから作成エージェントを開き、自然言語でアプリを作ったり直したりできるようになった。ただしエージェントはメーカー本人の GitHub アカウントで動き、課金は GitHub 側に付く。プロンプトとアプリの内容は GitHub の規約のもとで処理・保存される。

**詳細**: Power Platform ブログ（10/27）と Learn の一次 `canvas-authoring-agent`（preview）による。9月に GA した外部コーディングエージェント向けのプラグインとは別に、Studio の中で同じことができるようにしたものである。
- 有効化: 管理者が PPAC の Manage > Tenant Settings で「Agentic Coauthoring in Power Apps using GitHub」を有効にする。有効にした時点で規約に同意したことになる。メーカーは Studio で GitHub に接続して使う
- データと課金: ペインの通知は、プロンプトとアプリの文脈が GitHub に送られ、GitHub General Privacy Statement または GitHub DPA のもとで処理・保存されると明記している。使用量は GitHub の既存の課金プランで請求される
- 流れ: エージェントが Canvas App Plan（画面・データの使い方・前提）を示し、メーカーが承認すると画面・コントロール・Power Fx を書く。生成物は通常のキャンバスアプリで、手で編集を続けられる
- 制限: 米国だけ・英語だけで提供される。モデルは変更できない（画面の例は GPT-5.6 Terra）。エージェントは、データの追加・編集、画像の追加、アプリの保存・公開・共有ができない
- https://www.microsoft.com/en-us/power-platform/blog/power-apps/invite-agentic-coauthors-to-collaborate-with-you-directly-in-canvas-studio/
- https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/canvas-authoring-agent
