### 1. [新機能] Work IQ MCP に `retrieve` ツールが入った — エージェント向けの検索の課金がライセンスから Copilot Credits に移る

**要点**: Work IQ MCP に、M365 のデータと接続ソースを横断して検索する `retrieve` ツールがパブリックプレビューで追加された。Copilot Retrieval API から移行すると、課金は M365 Copilot ライセンスまたは従量課金から Copilot Credits に変わる。

**詳細**: Learn に `retrieve` と `migrate-retrieval-api` の2ページが新設された（10/13 18:10Z・`08b8fd0c`・`ms.date` 10/13・掲載歴ゼロ）。`tool-reference` も同じコミットで改訂されている。

- 返り値: モデルにそのまま渡せる引用付き Markdown と、コードで使う `retrievalHits`（URL・秘密度ラベルなどのメタデータ）が返る。Retrieval API はヒットごとの抜粋を返す方式だった
- 対象ソース: 1回の要求でメール・会議・Teams メッセージ・人物・OneDrive / SharePoint・Graph コネクタを指定できる。Retrieval API は1要求につき1ソースだった。Dataverse と Power BI はロードマップ上の扱いで、提供時期は確約されていない
- 前提: 委任認証と `WorkIQAgent.Ask` スコープが必要。Work IQ API を含む支出ポリシーへの割り当ても要る。M365 Copilot ライセンスや Retrieval API の従量課金設定があっても、これらは自動では構成されない
- 残すべき場合: 固定の REST スキーマや KQL / `filterExpression` に依存するアプリは、Retrieval API を残すか並行運用するよう書かれている。Work IQ のツールは **2026年11月**に REST でも使えるようになる予定
- Retrieval API の位置づけ: 廃止の告知は出ていない。同じ 10/13 に M365 Developer Blog が、SharePoint Embedded 向けの Retrieval API の使い方（Copilot Studio のメッセージメーターで従量課金）を紹介した。SharePoint Embedded MCP サーバーのパブリックプレビュー開始もあわせて告知している

- https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/work-iq/mcp/migrate-retrieval-api
- https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/work-iq/mcp/retrieve
- https://devblogs.microsoft.com/microsoft365dev/build-ai-powered-apps-without-creating-a-vector-database/

### 2. [新機能] Copilot のメモリが M365 の業務データから推論するようになる — 既定オンで、Purview の保持ポリシーは適用されない

**要点**: Message Center の MC1492154 によると、Copilot は M365 のコンテンツから得た推論を応答の文脈に使うようになり、10月中に全世界へ展開される。前提は「チャットで話したことだけを覚える」から「業務データからも推論して覚える」に変わる。

**詳細**: MC1492154（10/8 付）は、10月上旬に展開を始め10月下旬に完了すると書いている。管理者の対応は不要とされている。この内容は二次ミラーの要約から確認したもので、mc.merill.net はゲートウェイ拒否のため本文を取得できていない。一次の Roadmap **551195** は同じ機能を GA **November CY2026** で載せたままで、時期が一致していない。

- 利用者による停止: 「Settings > Personalization」の「Chat History and Work Insights」をオフにする
- 管理者による統制: Graph の `enhancedPersonalizationSetting` で管理する。Learn の `copilot-personalization-memory`（`ms.date` 9/2）は、この Enhanced personalization 制御が既定でオンだと明記している
- 統制の限界（Learn 一次）: Purview の保持ポリシーと保持ラベルはメモリに適用されない。メモリの操作は監査ログに残らず、管理者は何をメモリに入れるかを制限できない

- https://www.microsoft.com/microsoft-365/roadmap?id=551195
- https://learn.microsoft.com/en-us/microsoft-365/copilot/copilot-personalization-memory
