## AI開発ツール（本日の主役）

- **Anthropic — Claude Opus 5（`claude-opus-5`）を 7/24 投入**（一次: platform.claude.com release notes）。Opus 4.8 からの段階的改善ではなく step-change と位置付け。要点:
  - **1M トークンコンテキストがデフォルト兼最大**（小容量版なし）、**最大出力 128k**、**思考（thinking）がデフォルト ON**。価格は **$5/$25 per MTok と Opus 4.8 据え置き**（Fable 5 の半額でフロンティア級と主張）
  - **破壊的変更**: 思考の無効化（`thinking: {"type":"disabled"}`）は **effort が `high` 以下でのみ許可**。`xhigh`/`max` で無効化指定すると 400 エラー（Opus 4.8 では effort と独立だった）。思考 ON がデフォルトのため既存の `max_tokens` 見直しが必要
  - **挙動差**: 応答・成果物が長め、エージェント時の進捗ナレーションが増加、サブエージェントへの委譲を積極化、**自己検証を明示指示なしで実施**（旧モデル向けの「検証ステップを追加」指示は過剰検証を招くので削除推奨）
  - その他: prompt cache 最小長が 1,024→**512 トークン**に低下、会話途中のツール変更（beta）、`fallbacks` の `"default"` モード（beta）。Fast モードは Claude API のみ（$10/$50・Bedrock/Vertex/Foundry では未提供）
  - 提供面: **Claude API・Amazon Bedrock・Google Cloud（Vertex）・Microsoft Foundry**。Opus 4.8 も併存
  - https://platform.claude.com/docs/en/about-claude/models/whats-new-opus-5
- **Claude Code v2.1.219**（7/24 の 2.1.218 系から前進）: ① **既定 Opus モデルを Claude Opus 5 に切替**（1M コンテキスト・Fast モードは $10/$50）、② サンドボックス実行で許可リスト外ホストをプロンプトなしで拒否する `sandbox.network.strictAllowlist` 設定を追加、③ `/add-dir`・SDK でセッション途中に作業ディレクトリを登録した際に発火する `DirectoryAdded` フックを追加、④ サブエージェントのネスト対応強化（既定深さ3・環境変数で調整可）
  - https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- **GitHub Copilot CLI v1.0.75（7/24）／v1.0.74（7/23）**（7/20 の 1.0.73 から前進）: **1.0.75 = Claude Opus 5 対応を追加**。1.0.74 = 検索バーでの `?` をテキスト入力として扱う（ヘルプを開かない）・Open Plugin Spec v1 マニフェスト対応・IDE 統合の再接続信頼性向上
  - https://raw.githubusercontent.com/github/copilot-cli/main/changelog.md
- **Cursor / Devin**: Cursor 3.11（7/10）・Devin SWE-1.7（7/8）が直近のまま、新版なし。なお Cursor で 7/9 に登場した「Claude Honeycomb EAP」は Opus 5 の early-access だったと判明
