資料の冒頭に1回だけ置く、深い藍色（`secondary`）の表紙帯です。

- 構成：`pd-titleband` の中に `pd-titleband__eyebrow`（資料の種類）、`pd-titleband__title`（資料名）、`pd-titleband__meta`（日付・作成者）を順に置く。
- 資料名は「〜に関する調査結果」「〜のご提案」のように内容が分かる名詞句にする。疑問形や感嘆符は使わない。
- 1つの資料に1回まで。章の区切りには使わず、章は `heading-1` と余白（`space-section`）で区切る。
- 直後に Notice（前提・免責）を置く。
