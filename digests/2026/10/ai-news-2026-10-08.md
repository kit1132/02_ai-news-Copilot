### 1. [新機能] M365 Copilot Release Notes に10/6 バッチが載り、Copilot Search 内のチャットとコネクタ設定の事後編集が出た — 検索結果からそのまま対話できるようになり、コネクタの範囲修正にサポート依頼が要らなくなった

**要点**: Release Notes に 9/22〜10/6 分の7項目が加わり、全件が本ダイジェスト初出である。利用者は Copilot Search の結果を起点にチャットで追質問できるようになった。管理者は、コネクタのクエリ文字列とユーザー ID マッピングを作成後に自分で直せるようになった。

**詳細**: `release-notes` は `updated_at` 2026-10-06T21:16Z・`cf2b8e23` で、先頭 H2 が September 23 から **October 06, 2026** に変わった。
- Copilot Search と Chat の統合（512429・Windows / Web）: 検索結果をもとに、チャットペインで追質問・要約・コンテンツ生成ができる
- Regenerate（Web）: 応答末尾の「More options」から Try Again と Switch Model を選び、別の回答や別モデルの回答を得られる
- Copilot コネクタ: 管理者が M365 管理センター > 設定 > Search & intelligence > Data sources で、作成済み接続のクエリ文字列とユーザー ID マッピングのルールを編集できる。従来は作成時に固定され、変更にはサポート依頼が必要だった
- SharePoint（561038）: SharePoint Advanced Management の管理者が、Everyone / Everyone except external users に付与された権限をアイテム単位で一覧するレポートを Data access governance reports から出力できる
- PowerPoint（Windows）: Copilot ペインから独自のカスタムスキルを作成できる
- PowerPoint（Mac・555897）: プロンプトで SharePoint / OneDrive のファイル名を挙げると、添付しなくてもそのファイルを参照してプレゼンを作る
- Viva Insights（567005）: Copilot ダッシュボードと Consumption ダッシュボードに Cowork の利用・効果の指標が加わり、エクスポートと Consumption クエリ（クレジット使用量）で分析できる

- https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes

### 2. [新機能] Copilot Studio で Foundry IQ 連携が GA した — Azure AI Foundry で作ったナレッジベースを複数エージェントで使い回せるようになった

**要点**: Copilot Studio の9月アップデート記事（10/7）が、Foundry IQ 連携の GA を告知した。Foundry IQ の1つのナレッジベースを複数のエージェントから引用付きで参照でき、プライベートネットワーク経由でも接続できる。ナレッジを Copilot Studio 側で作り直す必要がなくなった。

**詳細**: 「Foundry IQ」は全 digest で掲載歴ゼロだった。手順ページ `agents-experience/foundry-iq-connect`（`ms.date` 2026-06-23・`2c9b59e9`）はまだ GA に合わせて改訂されていない。
- 前提: GitHub Copilot ハーネスのエージェントに限られ、UBB（Copilot Credits）の対象になる。接続できるのは1エージェントにつき1つまでで、Foundry 側でアクセス権を持つナレッジベースだけが選べる
- 認証: API キー、クライアント証明書、サービスプリンシパル、Entra ID 統合の4方式から選ぶ
- 検索精度の調整は Copilot Studio ではなく Azure AI Foundry 側で行う

- https://www.microsoft.com/en-us/copilot/blog/copilot-studio/new-and-improved-build-apps-extend-agents-and-transform-business-processes-in-microsoft-copilot-studio/
- https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/foundry-iq-connect
