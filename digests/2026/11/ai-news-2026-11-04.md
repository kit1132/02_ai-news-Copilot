## 今日のハイライト

### 1. [廃止+破壊的変更] Power Platform のプロンプトから Anthropic と Grok のモデルが 12/2 に外れる — プロンプトで Claude を選べる前提が消え、全段が OpenAI の GPT 系に揃う

**要点**: Copilot Studio・Power Automate・Power Apps のプロンプトで使える Claude Sonnet 4.6・Claude Opus 4.6・Grok 4.1 Fast と旧 GPT 系が 12/2 に退役する。そのモデルを使うプロンプトは、同じ段（Basic / Standard / Premium）の GPT 系へ自動で移る。段ごとの料金は変わらないが、応答の書きぶりは変わりうる。

**詳細**: MC1536101（11/3 公開・Feature update）。移行は自動で、退役モデルを指定したままにしても移行は止められない。
- Basic: GPT-4.1 mini → GPT-6 Luna
- Standard: GPT-4.1・GPT-5 chat・GPT-5.3 chat・Claude Sonnet 4.6・Grok 4.1 Fast reasoning → ChatGPT-latest
- Premium: GPT-5 reasoning・GPT-5.2 reasoning・Claude Opus 4.6 → GPT-6 Reasoning
- 求められる対応: 退役モデルを使うプロンプトと、それに頼るアプリ・フロー・エージェントを洗い出し、移行先モデルで出力の形式と後続処理を試す。料金は段単位で据え置きだが、実際の消費は入力・出力のトークン数で変わる
- エージェント本体のモデルも動く: MC1506318 が 11/3 に4版目へ更新され、GitHub Copilot ハーネスの移行先が2件変わった。GPT-5 Chat は GPT-5.6 Terra ではなく GPT-6 Luna へ、GPT 5.6 Sol は GPT-6 Sol ではなく GPT-6.1 Sol へ移る（11/12）。Claude Opus / Sonnet の旧版の退役日も別に告知するとしている
- https://mc.merill.net/message/MC1536101
- https://mc.merill.net/message/MC1506318

### 2. [廃止] 単体の Word / Excel / PowerPoint エージェントが撤去され、Copilot Chat の組み込み機能に置き換わる — エージェントを選んで呼ぶ操作が無くなり、Chat で頼む形だけになる

**要点**: M365 Copilot ライセンスの利用者は、11月中旬から順に、左レールとエージェント一覧で Word / Excel / PowerPoint エージェントを見つけられなくなる。ピン留めも @メンションもできなくなる。文書・ブック・プレゼンの作成と編集は、Chat で直接頼む。既存の会話の続きはできない。

**詳細**: MC1536062（11/3 公開・Feature update / User impact）。全世界で11月中旬に始まり、12月下旬に完了する見込み。
- 残るもの: これまでに作ったファイルは OneDrive / SharePoint の元の場所に、既存の権限と保持設定のまま残る。過去の会話の履歴も見られる
- 求められる対応: 管理者の設定は不要。単体エージェントを案内している研修資料・ヘルプデスク手順を、Chat から始める手順に書き換える
- 同じ時期の関連: Office in Copilot（MC1530611・11/3 更新、11月中旬に展開）で、Copilot アプリの中で Word / Excel / PowerPoint のファイルを作成・編集・共同編集できるようになる
- https://mc.merill.net/message/MC1536062

### 3. [料金] M365 Copilot のライセンスがない Copilot Chat 利用者に、11/9 から上限がかかる機能が増える — 無償の Chat で使える量が Microsoft の側で変わり、管理者は上限を見ることも変えることもできない

**要点**: 画像生成で先に入っていた公正利用の上限が、Copilot Chat の他の機能にも広がる。対象は商用テナントで M365 Copilot ライセンスを持たない利用者。上限は時間帯でも変わり、届いた機能は時間を置けば再び使える。無償の Chat を前提にした展開計画は、使える量が一定でないものとして見直す必要がある。

**詳細**: 同じ題名の通知が2本出ている。MC1536158 は「新しい上限は展開中」、MC1536163 は「11/9 から展開を始める」と書く。
- 上限の種類: 公正利用（1日の中でも変わる）と、機能ごとの上限。どちらも使えないときは製品の中で通知し、再開できる時期を示す。生成中の応答は止めない
- 管理者の側: 上限の確認も調整もできない。ヘルプデスクへの周知と、セルフサービスのライセンス要求の扱いの確認を勧めている
- https://mc.merill.net/message/MC1536163
- https://mc.merill.net/message/MC1536158
