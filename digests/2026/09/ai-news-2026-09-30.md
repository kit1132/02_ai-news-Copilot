## 今日のハイライト

### 1. [新機能] Copilot Studio の GitHub Copilot ハーネスに Hooks（preview）が入った — ツール呼び出しの前後に必ずワークフローを挟めるが、失敗時は素通りする

**要点**: メーカーは、セッション開始・プロンプト送信・ツール実行前後・エラーの各イベントでワークフローを必ず走らせ、ツール呼び出しを拒否できるようになった。エージェント任せだったガードレールを決定的に掛けられる。ただしフックが失敗やタイムアウトになると、エージェントは何もなかったものとして処理を続ける。

**詳細**: 一次は Learn `agents-experience/hooks-overview`（`ms.date` **2026-09-29**・`updated_at` 9/29 19:06Z・`6321110f`）で、本ダイジェストでは初掲載である。

- 設定場所: Build タブではなく、エージェントのコマンドバーにある More options > Hooks から追加する。動くのは保存して公開した後で、紐づけるワークフローも公開済みでなければ実行されない
- イベント: Start（pre-loop）/ User prompt submitted / Error / Pre tool use / Post tool use / After tool failure の6種。ツール系の3種は対象ツールを絞れる
- 止められるのは Pre tool use だけ: `permissionDecision` に `deny` を返すと呼び出しを遮断できる。ほかのイベントは `additionalContext` や `modifiedPrompt` / `modifiedParameters` / `modifiedResult` で文脈や値を差し替えられるが、処理は止められない
- 共通の入力: `metadata` として `conversationId` / `userAadObjectId` / `channel` / `agentId` などが毎回渡り、監査ログに利用者とエージェントを記録できる。未サインインの利用者ではユーザー欄が空になる
- ⚠️ 一次の注意書き: フックのワークフローが失敗・タイムアウト・読めない応答を返した場合、エージェントはフックが何も返さなかったものとして続行する。業務上必須のルールをフックだけに任せないよう明記されている。ワークフローを編集すると、それを参照する全フックに反映される

- https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/hooks-overview

### 2. [新機能] Copilot Studio の推定クレジット表示が Preview・Evaluate・Monitor の3面で一次に載った — 「試すまでコストが見えない」前提が変わる

**要点**: メーカーは、テスト中の会話と評価の実行について、推定の消費クレジットをほぼリアルタイムで確認できるようになった。確定値は Monitor に数時間遅れで出る。Roadmap の 571194〜571196（GA 期日 September CY2026）に対応する機能だが、Roadmap 上は3件とも期日当日の今日も `In development` のままである。

**詳細**: 一次は Learn `agents-experience/billing-credit-understand-display`（`ms.date` **2026-09-28**・`updated_at` 9/29 01:03Z・`860e5866`）で、本ダイジェストでは初掲載である。同一コミットで `analytics-agent-evaluation-*` 3本・`analytics-overview`・`preview-overview`・`preview-history`・`authoring-review-activity` も再ビルドされた。

- Preview: 現在のセッションの推定消費クレジットを積算表示する
- Evaluate: 評価の実行ごとに推定消費クレジットを表示する
- Monitor: 1日に数回更新され、`Total estimated credits used` が課金の基準値になると書く
- 推定値にはモデル・ツールとアクション・ハーネスとオーケストレーション部品の実行情報が使われ、UI には「計画用の推定値」である旨の情報アイコンが付く

- https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/billing-credit-understand-display
