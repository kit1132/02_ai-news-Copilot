## Microsoft Copilot（M365 Copilot）

- [新機能] **Copilot アプリの Home に Projects と Workspaces**（MC1535647・11/2）— Copilot アプリの利用者は、Home から Projects を開き、関連するチャット・Cowork タスク・ファイル・指示を1つにまとめて作業できるようになる。Standard release は10月下旬に始まっており、Deferred release は11月下旬に始まる

  - Workspaces: 左ナビの「Notebooks」が「Workspaces」に変わり、既存のノートブックは中身を残したまま変換される（10/31 にハイライトで既報）。使える機能はライセンスによって変わる
  - 求められる対応: Cowork へのアクセスを与えるスペンディングポリシーの対象者と、従量課金の構成を見直すよう案内している
  - https://mc.merill.net/message/MC1535647

## Copilot Studio / Power Platform

- [新機能] **Dataverse を使える場所の一覧**（Power Platform ブログ 11/2）— Microsoft が、Dataverse のスキルを入れられるプラットフォームを1本の記事にまとめた。新しく加わったのは n8n の組み込みノードで、ワークフローから Dataverse の標準・カスタムテーブルの行を作成・更新・upsert・取得・削除できる
  - Copilot Cowork: Customize から Microsoft Dataverse を選んで接続する。説明文からテーブル設計・サンプルデータ投入・アプリ公開までを承認カードつきで進める（10/28 に既報）
  - n8n: Get Many は列の選択・OData フィルター・並べ替え・expand・FetchXML に対応する。資格情報は委任ユーザーとアプリのみの両方に対応する
  - スキルの中身: 接続・クエリと一括取り込み・データモデリング・ソリューションのライフサイクル・セキュリティロール・環境管理・Finance and Operations の X++ の各スキルを、どのプラットフォームでも同じオープンソースのリポジトリから入れる
  - 統制: サインインしたユーザーの権限を超えない。資格情報は OS の資格情報ストアかメモリーに置き、テレメトリにはプロンプト・ツール引数・レコードの中身を含めない
  - https://www.microsoft.com/en-us/power-platform/blog/2026/11/02/dataverse-for-coding-agents-n8n-copilot-cowork/
- [据え置き] **What's New / 課金 / モデル表** — Copilot Studio What's New は `031b66d5`（`ms.date` 10/5）のままで、ハーネスの改名もまだ反映されていない。課金レート表（`4f4dfeab`）、課金・ハーネスの6本、PPAC の容量管理（`274fc069`）、ハーネスの費用管理ページ（`5691cde5`・旧名のまま）、モデル表3本、ガイダンスハブ（`acf1f32a`）に改訂はない。Released Versions（火曜の定例確認）は 2026.6.3 のまま125日たつ。Copilot Studio ブログ（先頭 10/28）と TC の Copilot Studio Blog（先頭 10/26）に新しい記事はない
