### 1. Teams のリテンションポリシーが10月に Copilot を外れる — 既存ポリシーで Copilot 会話を保持できていた前提が消える

**要点**: 10月以降、Teams のリテンションポリシーは Copilot の会話を暗黙に保持しなくなる。Copilot の保持期間は「Teams の設定を流用できる」前提から「専用ポリシーを別に作らないと素通し」へ変わる。

**詳細**: Roadmap **571306**「Microsoft Purview: Data Lifecycle Management-Legacy Teams retention policies covering Copilot will be treated as Teams-only」が **9/18 22:00Z** に起票された。ステータスは `In development`、GA 期日は **October CY2026**、対象は Worldwide（Standard Multi-Tenant）の Web である。本文は「Teams をスコープにした既存のリテンションポリシーが現在 Copilot の対話にも適用されている場合がある。今後の変更で、これらのレガシー Teams ポリシーは Teams 専用ポリシーへ変換され、Copilot ワークロードを暗黙に統制しなくなる」と書く。

- 一次ドキュメント側の記述範囲: `purview/retention-policies-copilot`（`ms.date` 2025-09-23・`updated_at` 2026-06-25T22:34Z）の Note は、M365 Copilot / Copilot Chat のメッセージが以前は `Teams chats and Copilot interactions` へ自動的に含まれていたこと、分離後は**新規作成**のポリシーで別ロケーションを選ぶことまでを書く。既存ポリシーが変換される話は書いていない
- 分離後のロケーション: Microsoft Copilot experiences（M365 Copilot / Security Copilot / Copilot in Fabric / **Copilot Studio**）、Enterprise AI apps（Entra 登録 AI アプリ / ChatGPT Enterprise / Microsoft Foundry）、Other AI apps（ChatGPT / Google Gemini / Copilot 消費者版 / DeepSeek）
- 保持対象: ユーザーのプロンプトと応答。Copilot Studio は M365 Copilot と同じ扱いで、他の生成 AI アプリは収集ポリシーでコンテンツ取得を有効にした場合に入る
- 削除の所要時間: 1日で削除する設定でも、コンプライアンス上の多段処理のため eDiscovery から消えるまで**最大16日**かかる
- 退職者の扱い: アカウント削除後も Copilot のメッセージは非アクティブメールボックスに残り、リテンションポリシーの対象であり続ける

⚠️ 10月という期日に対して、一次ドキュメントは未更新である。 Purview の What's New（`updated_at` 2026-09-16T17:34Z）September 2026 節にも本件の記載はなく、掲載は 9/17 に取り上げた Entra Global Secure Access 連携の1件のままである。管理者が Learn を読んで確認できるのは「新規ポリシーは分離されている」ところまでで、既存ポリシーがいつ変換されるかは **Roadmap 項目だけが一次**になっている。

### 2. Copilot Studio 標準ハーネスの既定モデルが GPT-5.5 Chat になった — モデルを固定していないエージェントの土台が入れ替わる

**要点**: 標準ハーネスの既定オーケストレーションモデルが全13リージョンで GPT-5.5 Chat になった。モデルを固定していないエージェントは、挙動と無効化時のフォールバック先が GPT-4.1 から入れ替わる。

**詳細**: `authoring-select-agent-model` の `ms.date` が **2026-09-17 → 2026-09-18** へ動いた（`updated_at` 2026-09-19T01:03Z・`git_commit_id` **93dade13**）。`Standard harness availability` 表は **15行**で、本ダイジェストが 9/18 に記録した「13モデル・既定は GPT-4.1」から入れ替わっている。新たに `Tag/Category` 列（Deep / Auto / General）と、タグごとの強み・レイテンシ・コスト・推論深度を並べた `Model use categories` 表が入った。

- Default: **GPT-5.5 Chat**（13リージョン全てで Default）
- GA: GPT-4.1 / GPT-5 Chat / Claude Sonnet 4.6 / Claude Opus 4.6（Deep）/ Claude Opus 4.7（Deep）
- Preview: GPT-5 Reasoning（Deep）と **GPT-5 Auto**（Auto タグ・ターンごとにクエリを動的ルーティングする）
- Experimental（米国の早期アクセス環境のみ）: GPT-5.3 Chat / GPT-5.4 Reasoning / GPT-5.5 Reasoning / Grok 4.1 Fast (Non-reasoning)
- Experimental（全リージョン cross-geo）: Mistral Medium 3.5
- Retired: GPT-4o / Claude Sonnet 4.5

ページ自身が定義する Default の意味は2つある。既定モデルは新しい GA モデルが出るたび**定期的に更新され**、かつ「選択したモデルが無効化または利用不可のときのフォールバック先」でもある。Retired の定義は「新しいモデルが既定になったとき旧既定が退役し、退役後1か月は使い続けられる」で、退役済みモデルの継続利用は別ページに分かれている。

⚠️ 政府クラウドの表は同じ動きをしていない。 `US Government availability` 表は GCC / GCC High / DoD の3列とも **GPT-4o が Default** のままで、商用13リージョンの表では同じモデルが Retired である。政府テナントは、商用側で退役扱いのモデルを既定として使い続ける形になっている。

⚠️ GitHub Copilot ハーネス側の表には **Default 行が無い**。 `agents-experience/authoring-agent-model-availability`（`ms.date` 2026-09-10・据え置き）の11モデル（GPT-5 Chat / GPT-5.5 Chat / GPT-5.6 Reasoning / GPT-6 Astra / Claude Sonnet 4.6 / Claude Sonnet 5 / Claude Fable 5 / Claude Fable 5.1 / Claude Opus 4.8 / Claude Opus 5 / Mistral Medium 3.5）に Default 表記は付かず、既定の概念は標準ハーネス側だけに存在する。この改訂は Copilot Studio What's New（July 2026 節が最新）にも Release Notes（August 25 バッチ）にも現れていない。

### 3. Copilot Cowork が政府クラウドへ来る（GA 2026年11月） — 統制の前提を商用と同じに読むと外す

**要点**: Copilot Cowork が GCC / GCC High のロードマップに載った（GA 2026年11月）。政府テナントの前提が「Cowork は商用クラウドだけ」から「11月着弾を見込んで統制を先に決める」へ変わる。

**詳細**: Roadmap **571637**「Microsoft Copilot (Microsoft 365): Copilot Cowork for Government Clouds」が **9/18 22:00Z** に起票された。ステータスは `In development`、GA 期日は **November CY2026**、対象クラウドは GCC と GCC High（DoD は含まれない）、対応面は Android / Desktop / iOS / Mac / Web の5つである。9/15 に出た Microsoft 365 G7（`Intelligence + Trust for the mission ahead`）の延長線上にあり、G7 の GA 後に政府クラウドへ展開される Copilot 機能の1つとして位置づけられている。

商用クラウドで既に確定している前提のうち、政府クラウドでそのまま読めないものが4つある。

- ブラウザー操作: `Copilot > Settings > View All > Cowork settings` の Allow browser access は**既定で無効**で、管理者が有効にするまで動かない。必要な Edge は 9/19 に引き上げられた **152.0.4191.53** 以上である
- Web 検索: 政府クラウド（GCC / GCC High / DoD）では Copilot の Web 検索が**既定オフ**で、商用の「未構成なら使える」とは逆である
- 既定モデル: Copilot Studio の標準ハーネスは政府クラウドで GPT-4o が Default のままで、商用側では Retired である（ハイライト2参照）
- DLP: Cowork 向けの Purview DLP（Roadmap **570845**・Preview 9月 / GA 10月）は Worldwide (Standard Multi-Tenant) のみを対象としており、政府クラウドは対象外である

- https://www.microsoft.com/microsoft-365/roadmap?id=571637
- https://www.microsoft.com/en-us/microsoft-cloud/blog/industry-government/government-operations-and-infrastructure/2026/09/15/introducing-microsoft-365-g7-intelligence-trust-for-the-mission-ahead/
