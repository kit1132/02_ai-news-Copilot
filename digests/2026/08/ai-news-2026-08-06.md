### 1. Web グラウンディングのドメイン除外がロールバックされた — 7/27・8/3 に確認した「導入可」の前提が消えた

**要点**: Microsoft は、M365 Copilot のドメイン除外を全世界展開から2週間ほどで撤回した。前提が「GA 済みで今から設定できる機能」から「提供停止・再設計待ち」へ戻り、除外リスト前提で組んだ Web グラウンディングの統制計画は保留になる。

**詳細**: 本ダイジェストは 7/27 に MC1411435 として、8/3 に一次ページの仕様として掲載していた機能である。8/4 付で Tech Community に「Update: Domain Exclusion for Microsoft 365 Copilot」（記事ID 4543648）が投稿され、早期適用テナントからも機能が引き上げられた。

- 撤回の理由は公式には示されていない。二次報道は、許可リストではなく**除外リスト方式**への管理者の不満を挙げている。「悪いサイト」を管理者が数え上げ続ける運用になり、上限1,000ドメインを使い切りやすいという指摘である
- Microsoft は機能の重要性を認めたうえで次の手を検討中とし、続報をコミュニティに出すとしている。再提供の時期は示されていない
- ⚠️ **Learn の一次ページは削除も注記もされないまま残っている**。`copilot/domain-exclusion` は本日時点でも、`ConfigureTenantDomainExclusions.ps1` による Get / Create / Update / Delete の手順、上限1,000件、サブドメイン2階層まで、Search 管理者または全体管理者、除外が効くのは Web ページ結果のみ、という仕様を掲載し続けている。**Learn を読んだだけでは撤回に気づけない**
- 記事本文は本日 403 で一次取得できず、内容は WebSearch 経由の要約に依存している（8/5 に復旧していた techcommunity の記事 HTML が再び 403 になった）

- https://techcommunity.microsoft.com/blog/microsoft365copilotblog/update-domain-exclusion-for-microsoft-365-copilot/4543648
- https://learn.microsoft.com/en-us/copilot/domain-exclusion

### 2. Copilot Studio の Release Wave 計画ページは M365 Roadmap へ 301 リダイレクトしていた — 半期計画からの追跡は終了している

**要点**: Copilot Studio の `planned-features` は en-us・ja-jp とも `aka.ms/MCStoM365Roadmap` へ恒久リダイレクトしていた。Copilot Studio の Preview / GA 予定日は半期リリース計画では追えず、M365 Roadmap を一次にする必要がある。7/27 から続く取得異常の正体でもあった。

**詳細**: 7/27 以降、Microsoft Learn MCP が当該 URL に対して M365 Roadmap の本文を返す現象が続き、B-012 として「Learn MCP の誤応答」の疑いで台帳に載せていた。本日 WebFetch で直接叩いたところ HTTP 301 が返り、誤応答ではなく**サーバー側の恒久リダイレクト**だったことが確定した。

- リダイレクト先は `https://www.aka.ms/MCStoM365Roadmap`（MCS to M365 Roadmap）で、en-us と ja-jp の2経路とも同じ挙動を示した
- Power Platform 全体版（`release-plan/2026wave1/`）と Power Automate / Power Apps 配下の `planned-features` は引き続き正常に取得できる。**リダイレクトは Copilot Studio 配下だけ**である
- 実務上の影響は、Copilot Studio の GA 予定を月単位で一覧できる表が消えたこと。Power Automate / Power Apps は緑チェックと月表記で GA 進捗を差分監視できるが、Copilot Studio は同じ方法が使えない
- 台帳の B-012 は「Learn MCP の障害」ではなく「ソース定義が実体と乖離」として根拠を確定した。M365 Roadmap をプライマリに切り替える提案の前提が揃った

- https://learn.microsoft.com/en-us/power-platform/release-plan/2026wave1/microsoft-copilot-studio/planned-features
