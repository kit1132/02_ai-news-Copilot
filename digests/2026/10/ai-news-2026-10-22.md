### 1. [料金+新機能] Copilot Studio に Customer Conversation ハーネスがプレビューで加わった — 顧客対応の音声・チャットエージェントも従量課金の枠に入る

**要点**: 顧客向けの音声・チャット対応に特化したハーネスが、標準・GitHub Copilot・Copilot チャットに続く4本目として公開された。課金は GitHub Copilot ハーネスと同じ従量課金で、構築・テスト・評価の段階からクレジットを消費しうる。顧客対応エージェントの試算は、公開後に課金が始まる標準ハーネスの前提では立てられなくなった。

**詳細**:
- 構成: プライマリエージェントの下に専門のサブエージェントを置き、それぞれに人の担当者へのエスカレーション経路を持たせる。Foundry で作ったエージェントを接続エージェントとして加えられる。GA 時にはサブエージェントごとにモデルを選べるようになる
- スキル: 生成型スキルと決定論的なトピックを、1つのエージェントの中で混ぜて使える（従来はどちらか一方だった）
- 音声: 音声モデルとボイスフォント、話し方の指示、DTMF の挙動を設定でき、電話番号を取得してそのまま公開できる。同日発表の Microsoft Contact Center Intelligence と組み合わせて、声紋による本人確認と、Teams Phone・メール・ライブ担当者へのエスカレーションを使える
- 課金: Learn `billing-credit-overview` が 10/21 13:04Z `c19a540a`（`ms.date` 10/6）に改訂され、対象が「GitHub Copilot ハーネス」と「Contact Center Intelligence の Self-Service / Customer Assist Agent」の2つになった。会話の消費量は複雑さ（軽・中・重）と経路（デジタル・GenAI 音声・プレミアム音声）で変わるとしているが、具体的なクレジット数は図だけで、本文に数値はない
- Learn: `agents-experience/` 配下に `-customer-conversation` 付きのページが41本新設された（目次の Copilot Studio 側は計474リンク）

- https://techcommunity.microsoft.com/t5/copilot-studio-blog/introducing-the-customer-conversation-harness-in-microsoft/ba-p/4563954

### 2. [料金+予定] GPT-6 Astra と Claude Fable 5.1 が 11月に Copilot Chat と Word / Excel / PowerPoint のモデル選択に入る — 使えるのは UBB を有効にしてクレジットを割り当てた利用者だけ

**要点**: MC1519122 によると、UBB（従量課金）モデルが Copilot アプリの Chat と Word / Excel / PowerPoint のモデル選択に、11月上旬から中旬にかけて GA で展開される。ライセンスを持っていても、管理者が UBB を有効にしてクレジットを割り当てない限り、利用者はこれらのモデルを選べない。

**詳細**:
- 対象: M365 Copilot のユーザーサブスクリプションライセンス（USL）を持ち、UBB が有効な利用者。クレジットの管理は M365 管理センターの Agent 365 コスト管理で行う
- 管理者の作業: USL の確認、対象者への UBB の有効化、クレジットの割り当て。クレジットを使い切ったときの追加申請の手順を社内に周知することも求めている
- 予定: 利用者が管理者に追加のクレジットを申請する機能は、今回の展開の後に出す予定としている（時期は未記載）
- 経緯: MC1479276 の続報で、Roadmap ID は 571400。両モデルは 9/2・9/4 に Microsoft Copilot での提供が告知されていた。通知は 10/21 公開で、タグは New feature / User impact / Admin impact

- https://mc.merill.net/message/MC1519122

### 3. [新機能] Copilot Studio の Copilot Chat エージェント（宣言型エージェント）に、トピックや ALM が 10/26 に GA で加わる — 宣言型でも決定論的な会話と環境ごとの版管理ができる

**要点**: MC1518233 によると、Copilot Studio で作る Copilot Chat エージェントに、トピック、接続エージェント、評価、監視、環境ごとのデプロイが **10/26** に GA で加わる。人事の定型回答のような「毎回同じ答えを返す」エージェントを、宣言型のまま開発・テスト・本番の3環境で回せるようになる。

**詳細**:
- 追加される機能:
  - トピック: 決定論的な会話フロー
  - 接続エージェント: 作業を別のエージェントに委任する
  - 評価と監視: 品質の改善と利用状況の追跡
  - プレビュー: Copilot Chat 上の見え方を Activity Map 付きで確認する
  - ライフサイクル管理: 開発・テスト・本番の環境ごとに別の版をデプロイする
- 管理者の対応は不要。社内の開発手順書と研修資料の更新を推奨している

- https://mc.merill.net/message/MC1518233
