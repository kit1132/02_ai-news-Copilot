## 今日のハイライト

### 1. [料金+予定] Copilot Business の従量課金の既定オンが、12/1 から2027年1〜3月へ再び延期された — 12/1 に課金設定が自動で入る前提が消えた

**要点**: CSP で新規購入する Copilot Business の従量課金（UBB）が既定で有効になる時期は、12/1 から Microsoft の FY27 Q3（2027年1〜3月）に移った。11/2 に予定していた Partner Center のサンドボックス提供も延び、新しい日付は未定である。12/1 に合わせた準備は、時期を引き直す必要がある。

**詳細**: Partner Center 11月アナウンスの「Availability update」（11/3 付、ページ改訂は 11/4 18:46Z・`cd71f065`）。延期は 10/2 に続いて2回目（11/2 → 12/1 → FY27 Q3）。
- 変わらない点: 既定の支出上限は1ユーザーあたり月 4,000 Copilot Credits で、管理者が変えられる（例: 100ユーザーなら月 400,000 Credits まで）。課金方式の既定は従量課金（pay-as-you-go）。新規購入の時点で、同じテナントの既存 Copilot Business ライセンスにも UBB が有効になる
- 対象になる体験: Copilot Cowork、Work IQ API、GitHub Copilot ハーネス（ページの表記のまま）
- サンドボックス: 新しい日付は Partner Center で告知される。GA の少なくとも30日前から試せる
- 対象市場: 新しい時期は全市場に適用される。初回は対象外とされていたオーストラリア・ベルギー・ブラジル・フランス・ドイツ・インド・イタリア・韓国・オランダ・ポーランド・スペインも含む
- https://learn.microsoft.com/en-us/partner-center/announcements/2026-november

### 2. [新機能] Copilot Studio が MCP サーバーを出し、Claude Code や Codex、GitHub Copilot からエージェントを作れるようになった — 構築の入口が Copilot Studio の画面の外にも広がった

**要点**: 開発者は、Copilot Studio MCP サーバーを使い、手元の CLI やエージェントからエージェント・ワークフローの作成、テストと評価、公開、トラブルシューティングまでを自然言語で行えるようになる。同じ10月アップデートで、Copilot Studio の Work IQ が GA になり、ワークフロー機能3件も GA になった。

**詳細**: Copilot ブログ 11/4「New and improved: Agents that are persistent, agents for customer conversations, and improved maker experience」。ハーネスの名前は新名（Microsoft Copilot ハーネス）で書かれている。
- Copilot Studio MCP サーバー: 対応先として GitHub Copilot・Claude Code・OpenAI Codex を名指ししている。アクセスは組織の権限とポリシーに従う。作成・テスト・トラブルシューティング用のスキルが組み込まれている
- Work IQ: Copilot Studio で GA になった。メール・会議・ファイル・会話・組織関係を横断してエージェントの文脈に使える
- ワークフローの GA 3件: Copilot Chat / Cowork の呼び出し、抽出ノード（文書・メール・画像から値を取り出す）、複数作成者での共同編集
- コネクタ接続を会話の中で完了: Microsoft Copilot ハーネスのエージェントと、標準ハーネスのカスタム Web エージェントで GA になった
- Cowork の Copilot Studio スキル: Frontier で、M365 ライセンスの利用者が Cowork からエージェント・アプリ・ワークフローを作れる。作られるのはマネージドソリューション
- エージェントアカウント: Frontier のプライベートプレビューで、エージェントが自分の承認済み資格情報とスコープを持つ権限で作業し、業務プロセスのメモリーとトリガーで自分から動けるようになる
- コスト: メーカーが構築・テスト中の Credits 消費を見られるようになり、ワークフローの実行・ノード単位のレポートも加わった。M365 管理センターのコスト管理（preview）は既報
- https://www.microsoft.com/en-us/copilot/blog/copilot-studio/new-and-improved-agents-that-are-persistent-agents-for-customer-conversations-and-improved-maker-experience-in-microsoft-copilot-studio/

### 3. [破壊的変更+料金] Teams の Intelligent call delegation が 11/17 から従量課金のパブリックプレビューに移り、支出ポリシーがないと止まる — Frontier では無償だった着信の振り分けに、管理者の課金設定が必要になる

**要点**: Intelligent call delegation（AI が着信を確かめて文脈を集め、Bookings で折り返しの予約も入れる機能）は、早ければ 11/17 に Frontier からパブリックプレビュー（Ring 3.6）に移る。プレビューは Copilot Credits の従量課金で、管理者が支出を構成しない限り課金は始まらない。その代わり、Frontier から来たテナントでは着信の振り分けが止まる。

**詳細**: MC1537490（11/3 公開・New feature / Admin impact・Roadmap 565216）。パブリックプレビューは11月中旬〜12月中旬、GA は2027年1月中旬〜下旬の見込み。
- 求められる対応: M365 管理センターで支出ポリシーを作り、エージェントとサービスで Intelligent call delegation だけを選ぶ。対象のユーザー・グループを決めてから割り当てる。必要に応じて M365 Copilot のユーザーライセンス（USL）も確かめる
- 対象: Frontier プレビューで使っていたテナントと、Ring 3.6 で使い始めるテナント。対応製品は Teams・M365 Copilot（Premium）・Bookings 連携
- https://mc.merill.net/message/MC1537490
