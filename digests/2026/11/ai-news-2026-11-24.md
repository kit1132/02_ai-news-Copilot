## 今日のハイライト

### 1. [廃止+破壊的変更] PPAC のデータエクスポートでインベントリが 12/1 に出力されなくなる — データレイク経由の在庫集計は残り7日で Inventory API へ移す必要がある

**要点**: PPAC のデータエクスポート（プレビュー）が非推奨になり、段階的に退役する。第1段として 12/1 以降はインベントリのデータが出力されない。使用状況と環境のエクスポートは当面続く。データレイクのインベントリを前提にした集計は、12/1 までに Power Platform inventory API へ移さないと更新が止まる。

**詳細**: 非推奨一覧（`important-changes-coming`）の 11/23 19:03Z の改訂（`a406dde7`・`ms.date` 11/23）で、先頭に節「Deprecation of data export (preview)」が加わった（見出しは前回の106本から107本へ）。
- 影響: 12/1 以降、データエクスポートはインベントリを出力しない。出力済みのデータはデータレイクに残る
- 対象外: 使用状況（usage）と環境（environment）のエクスポートは今と同じく動く。これらも後日、事前告知のうえで退役する
- 必要な対応: インベントリの取得を Power Platform inventory API へ切り替える。Learn は移行前の比較ページとフィールド対応表を案内している
- Message Center の告知は 11/24 時点で見つかっていない（WebSearch でも該当なし）
- https://learn.microsoft.com/en-us/power-platform/important-changes-coming
- https://learn.microsoft.com/en-us/power-platform/admin/self-service-analytics

### 2. [新機能] Copilot Agent Kit 11月版で、メーカーが Copilot Credits の追加を申請し管理者が承認できるようになった — クレジット配分の依頼をメールではなく Kit の承認フローで回せる

**要点**: Power CAT の Copilot Agent Kit（11/23・`CopilotAgentKit-November2026`）が PowerShield を Request Center に改め、コネクタ申請と Copilot Credits の申請を1か所にまとめた。メーカーは追加クレジットやテナントの余剰クレジットの利用を申請でき、管理者の承認がそのまま Power Platform に反映される。

**詳細**: 非互換の記載はなく、5〜8月版にあったコードコンポーネント有効化の注意書きも無い。
- Agent Inventory: 統計の「Missing owner」が「Web search enabled」に置き換わった
- Conversation Analyzer: 画面を刷新し、Conversations タブで会話 ID から会話を探して分析・デバッグできるようになった
- Agent Value Summary: グラフとカードから、絞り込み済みのエージェント一覧（CSV 出力可）へ掘り下げられるようになった
- Agent Debugger: 推論ステップの時間が 0 秒と表示される不具合を直し、Latency タブにオーケストレーターの推論時間を出すようになった
- Microsoft Copilot ハーネス対応: ハーネス名を「GitHub Copilot」から「Microsoft Copilot」へ改め、標準エージェントの移行可否・移行後コピーと元エージェントの比較・ハーネス適合の助言を加えた。Work IQ の表記をプレビューから GA に直した
- https://github.com/microsoft/Power-CAT-Copilot-Studio-Kit/releases
