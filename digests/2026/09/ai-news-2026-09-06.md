### 1. GPT-6 Astra が Copilot Cowork と Copilot Studio に初日から入った — 委任できる作業の粒度が上がる

**要点**: 9/4 に GPT-6 Astra の提供が始まり、前提が「Cowork と Copilot Studio の最上位は Opus 5 / Fable 5.1」から「コンテキスト105万トークンの推論モデルを選べる」へ変わった。

**詳細**: Tech Community の M365 Copilot Blog に **9/4 20:28Z** 付「Available today: OpenAI GPT-6 Astra in Microsoft Copilot」が出た（全 digest に掲載歴ゼロ）。記事は、作業を小さく割って逐次誘導するのではなく大きな単位で委任し、利用者は結果のレビューと判断に時間を使う形になると説明し、Work IQ が既存権限の範囲でファイル・会議・チャット・業務データへ接地させるとする。展開は当日から順次で、提供可否は地域と組織により異なり、管理者は Microsoft 365 管理センターから制御する。提供範囲は Cowork と Copilot Studio の2面で、9/2 の Claude Fable 5.1 と同じ形であり、7/24 の Claude Opus 5（in Microsoft 365 Copilot）とはスコープが異なる。モデル仕様は Learn の Foundry ドキュメントに `gpt-6-astra`（バージョン **2026-09-03**）として載っている。

- コンテキストウィンドウ: 1,050,000 トークン（入力 922,000 / 出力 128,000）で、学習データは 2026年4月まで
- 対応機能: Responses API・Chat Completions API・ストリーミング・構造化出力・関数とツールの並列呼び出し・reasoning effort・verbosity・`logprobs`・computer use に対応し、マルチエージェントオーケストレーションは Preview
- 非対応: `temperature` と `top_p` は使えない
- クォータ: アクセス申請は不要だが、階層によってはクォータ申請が要る（**Tier 5** と Tier 6 は既定でクォータあり）
- 安全制御: 安全システムが高リスクと判定した場合、推論時に分類しきい値を変更し、システム生成の安全指示をプロンプトへ補う強化制御が適用されうる

⚠️ Copilot Studio のモデル一覧にも Cowork のモデル一覧にも Astra の行は無い（下の「モデル可用性」参照）。Azure ブログ側の一次は `azure.microsoft.com` がゲートウェイ拒否のため読めておらず、上記の仕様は Learn の Foundry ドキュメントを一次とした。
