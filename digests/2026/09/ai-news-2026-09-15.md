### 1. Copilot Credits の統制単位が「環境」に定まった — 公開前のビルド段階から課金が始まるため、エージェント単位の事後統制では間に合わない

**要点**: Copilot Studio のガイダンスハブに Copilot Credits の統制手順が新規公開された。統制単位は公開済みエージェントではなく環境で、消費はビルド・プレビュー段階から始まる。前提が「公開後にエージェントを絞る」から「環境を分類して事前に境界を引く」へ変わる。

**詳細**: `microsoft-copilot-studio/guidance/govern-credit-consumption`（`ms.date` **2026-09-14**・`updated_at` **2026-09-14T19:03Z**）が公開された。全 digest を grep して掲載歴ゼロを確認している。ガイダンスハブの新規記事は 8/28 以来 **17日ぶり**で、索引側の `sec-gov-intro` も同時刻に更新され本記事へのリンクが加わった。対象は GitHub Copilot ハーネスで動くエージェントとワークフローである。

- **統制は4層**: テナント（購入済み容量と、誰が容量を割り当てられるか）、環境（前払い割当・テナントプールからの引き当て・従量課金）、エージェント（月次上限・通知しきい値・ハードストップ）、運用プロセス（コスト責任者・アラートのトリアージ・例外承認）
- **環境を3分類する**: 探索とプロトタイピング / テストと検証 / 資金付き本番。分類ごとに承認済みの容量姿勢と例外プロセスを定義し、新規環境とエージェントを定期的に検出して同じ手順を回す
- **Inventory API** で検出する: Copilot Studio のエージェントリソースを `properties.harness` フィールドで絞り込み、値 `GitHub Copilot` で抽出する。ページサイズを設定し、返された skip token を継続が尽きるまで追う（追わないと1回の応答に全件が入らない）
- **監視と通知**: PPAC の Manage Agents と消費レポートで上限と消費を確認する。規模が大きい場合は Power Platform API の entitlement insight 操作で消費データを取得する

⚠️ PPAC に**テナント全体の既定エージェント上限は無い**。 組織として新規エージェントに標準の上限を課す場合、定期実行または自動化で個別エージェントに適用するしかない。上限はユーザーではなくエージェントに掛かるため、メーカー1人が作れるエージェント数を前提に上限値と増枠の承認経路を設計する必要がある。

⚠️ テナントのアドオン容量割り当て設定で環境管理者に割り当てを許可すると、その管理者は担当環境だけでなく**テナント内の全環境**に対する割り当て権限を得る。 ページは「そのテナント全体のアクセスが意図的でない限り、割り当てはテナント管理者に限定しておくこと」と明記する。

⚠️ 環境の容量制御は、その環境の**全 Copilot Studio ワークロード**に掛かる。 GitHub Copilot ハーネスのエージェントだけでなく、標準ハーネスのエージェント・エージェントフロー・ワークフロー・プロンプトも同じ割当を共有するため、割当や超過設定を変える前に環境内の全ワークロードを確認する。新規環境はテナント容量からの引き当てが有効な状態で現れることがあり、既存環境の構成も承認済みの統制からドリフトする。

⚠️ エージェント単位の上限は**環境の合計消費を抑えない**。 前払いの消費を封じ込めるには割当額を定めたうえで「テナントの利用可能な容量から引き当てる」を無効にする。従量課金の環境では Azure の予算はアラートを出すだけで消費を止めない（**9/1** に開発環境と試用環境が従量課金へ移行済み）。また環境の entitlement 消費量から個別エージェントが上限の何%に達したかを推定してはならず、この値は集計値で per-agent のしきい値を持たない。

### 2. PowerPoint の Brand Kit と Skills が GA した — ブランド準拠とレビュー手順が個人の運用から管理者の配布物に変わる

**要点**: PowerPoint の Brand Kit と Skills が GA した。Microsoft 365 Copilot ライセンスがあれば当日から使え、管理者は承認済み Skill をユーザー・グループ・組織全体へ発行できる。ブランド準拠とレビュー手順が、各自の運用から配布される標準へ変わる。

**詳細**: Tech Community の Microsoft Copilot Blog に **2026-09-14 15:00Z** 付「Brand Kit and Skills in Copilot in PowerPoint」が公開された。記事は「Brand Kit in PowerPoint と Skills in PowerPoint は本日 Microsoft 365 Copilot ライセンスで一般提供される」と明記している。

- **Brand Kit**: 組織のテンプレート・画像・アイコン・フォント等の資産を PowerPoint の作成体験に取り込む。承認済みのキットを選んでから作成すると、Copilot が「オンブランドとは何か」を推測せずに組織の視覚的アイデンティティを前提にスライドを生成・更新する
- **厳格なブランド準拠モード**: ブランド管理者が有効にすると、Copilot は独自のレイアウトを提案せず承認済みレイアウトだけに従う。スライド単位の指示もキット内に置けるため、チームが作る資料に同じ指示が反映される
- **組み込みの Skills**: `@Prepare for Questions`（スライド単位で想定質問に備える・GA）、`@Review Presentation`（スライドごとの経営層目線のフィードバック・GA）、`@Visualize Slide`（スライドの内容を図版やインフォグラフィックに変換）
- **個人 Skill と組織 Skill**: 利用者は独自ワークフローを個人 Skill として作成・アップロードし、Copilot チャットペインで管理できる。管理者は承認済み Skill を特定のユーザー・グループ・組織全体へ発行でき、各自がアップロードする必要がなくなる

⚠️ Release Notes に**本件の GA は載っていない**。 全文（H2 **83本**）に `brand kit` は38箇所あるが、いずれも **July 01** バッチ（Copilot Chat の視覚生成へのブランドキット適用）と **July 15** バッチ（ブランドガイドライン文書からのブランドキット自動生成）で、PowerPoint の Brand Kit / Skills の GA を書いた項目は存在しない。Roadmap 項目も無い。
