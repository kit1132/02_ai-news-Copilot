## 今日のハイライト

### 1. [破壊的変更+新機能] Copilot Studio エージェントの外部サービス接続を会話の中で設定できるようになり、Standard ハーネスのカスタム Web UI は改修が必要になる — 「接続は別画面で設定して会話をやり直す」から「会話の中で設定して続ける」に変わり、自前のキャンバスはこの流れに対応しないと接続を張れなくなる

**要点**: 利用者は接続が必要になった時点で、会話を離れずに必要な分だけ設定し、そのまま会話に戻れるようになる（12/31 までに GA）。Standard ハーネスでカスタム Web UI に公開しているエージェントの開発者は、新しい接続ウィンドウを開き、設定成功後に会話を続ける実装を足す必要がある。

**詳細**: MC1548034（11/11 公開・Feature update・Microsoft Copilot (Power Platform)）。
- 対象の面: Microsoft Copilot・Teams・Web Chat。有効な既存の接続があれば再利用する
- 統制: どのコネクタ・接続を使えるかは、これまでの組織の統制がそのまま決める
- 開発者の作業: 「Support connection setup in a custom canvas」の手順で、接続ウィンドウの起動と、成功後の会話の再開を実装する
- https://mc.merill.net/message/MC1548034
