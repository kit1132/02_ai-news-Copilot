### 2. [新機能] Copilot Studio のエージェントを MCP サーバーまたは A2A エージェントとして外部に公開できる（プレビュー） — 外部の IDE やエージェントから呼べるようになる

**要点**: メーカーは、公開済みのエージェント（GitHub Copilot ハーネス）に「MCP client」と「A2A client」のチャネルを追加できるようになった。外部の MCP クライアントや他社のオーケストレーターからエージェントを呼び出せる。これまでの公開先は Teams などのチャネルだけで、呼ぶ側のエージェントとして使う経路は無かった。

**詳細**: 一次は Learn `agents-experience/publication-channels-mcp-agent-to-agent`（`ms.date` **2026-09-30**・`updated_at` 10/1 01:03Z・`ff24411a`）。本ダイジェストでは初出である。

- 提供範囲: early release cycle 環境のみ。Add a channel ダイアログに出てこない環境は、まだロールアウトの対象外である
- 認証: Entra ID のアプリ登録が必要。委任アクセス許可は `MCS.InvokeAsMCP` と `MCS.InvokeAsA2A` で、API の ID は `6f46e6ed-07bf-4616-80f0-47546850f654`。リクエストごとにサインインしたユーザーのアクセス権を確認する
- クライアントの要件: OAuth 2.0 認可コードフローに対応していること
- 課金: 利用・構築・テスト・評価のすべてで Copilot Credits を消費しうる

- https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/publication-channels-mcp-agent-to-agent

### 3. [新機能] GPT-6.1 Sol と Claude Sonnet 5.5 を Copilot で選べるようになった — 今日から Cowork / Studio で使え、Office アプリでは来週から USL の範囲で使える

**要点**: Copilot Cowork と Copilot Studio の利用者は、9/30 から GPT-6.1 Sol と Claude Sonnet 5.5 を従量課金で使えるようになった。来週からは Word / Excel / PowerPoint / Chat にも段階的に展開され、そちらはユーザーライセンス（USL）の利用上限の範囲で使える。9/22 に告知した Opus 5.5・GPT-6 Sol に続く追加である。

**詳細**: 一次は Tech Community の Microsoft Copilot Blog（9/30 23:28Z・ba-p/4560801）。

- 上限に近づくと利用者に警告が出る。利用者は Auto に切り替えるか、別のモデルを選べる
- 提供範囲はライセンス・アクセス・リージョンによって異なる。最新の提供状況は AI at Work Roadmap と Release Notes を参照するよう書いている

- https://techcommunity.microsoft.com/t5/microsoft-copilot-blog/available-today-openai-s-gpt-6-1-sol-and-claude-sonnet-5-5-in/ba-p/4560801
