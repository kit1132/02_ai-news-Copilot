### 1. SharePoint Copilot Apps が Copilot Components に改称され、GA は10月に置かれた — 無償で試せるのは GA までで、課金前提は未確定のまま残る

**要点** SharePoint Copilot Apps が **Copilot Components** に改称され、SPFx 1.24 Beta 3 で公開プレビューに入った。GA は 2026年10月で、プレビュー中は無償だが GA 時の課金モデルは未確定のまま置かれている。

**詳細** 一次は M365 Developer Blog の 8/27 付「SharePoint Framework (SPFx) roadmap update – August 2026」で、7/9 に「SharePoint Copilot Apps」の名で公開プレビューが告知された機能が、プレビューと GA を通して Copilot Components という名称に変わった。実装は React と標準 JavaScript ライブラリで、MCP Apps 経由で接続し、Copilot の会話にインラインまたは全画面で描画される。ロードマップは3段階に分かれる。

- **SPFx 1.24 Beta 3**: 2026年8月に出荷済み。Copilot Components の公開プレビュー更新と、SPFx ソリューションの React 18 対応を含む
- **SPFx 1.24 GA**: 2026年10月。Copilot Components の GA 目標時期でもあり、React 18 対応が本展開に入る
- **SPFx 1.25**: 2026年12月〜2027年1月。SPFx CLI が GA して Yeoman ジェネレーターを置き換え、ナビゲーションカスタマイザーが加わる

⚠️ 課金条件は**プレビューと GA で切り替わる**。プレビュー中は Copilot ライセンス不要かつ従量課金なしで動くが、GA 時のライセンスモデルは「10月までに確定する」と書かれているだけで、金額も課金単位も現時点の一次に存在しない。無償で検証できる期間は残り約2か月である。あわせてエンジニアリングチームの直接支援付きで業務プロセスに Copilot Components を当てるハンズオン枠が、人数限定で募集されている。
