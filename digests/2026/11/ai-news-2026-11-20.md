### 2. [破壊的変更] Copilot Code のローカル Sandbox が11月下旬に既定でオンになり、利用者はオフにできなくなる — 管理者がポリシーを明示していないテナントでは、ローカルのファイル・ネットワークアクセスが許可範囲に絞られる

**要点**: 今は既定オフで利用者が切り替えられる Windows のローカル Sandbox が、11月下旬からポリシー未設定のテナントで既定オンになり、利用者は切れなくなる。ローカル実行の接続先は許可範囲に入れておく前提に変わる。

**詳細**: MC1519871 の 11/18 更新（Frontier 向け。GitHub Copilot CLI のサインインは前日に既報）。
- 現在: Sandbox ポリシーが未設定なら既定でオフで、利用者が設定を変えられる
- 11月下旬から: 既定でオンになり、利用者はオフにできない。管理者が明示したポリシーはこの既定より優先される
- 前提: ローカルのコーディングセッションはもともと既定で無効で、M365 管理センターの Code execution location を Cloud and local にしたときだけ PC で使える
- https://mc.merill.net/message/MC1519871

### 3. [新機能+仕様] Work IQ の MCP 経由で、許可されたエージェントが利用者のメモリを読めるようになる — Copilot の個人設定が、自社エージェントにも渡る

**要点**: カスタム指示や保存したメモリを、許可済みの自社エージェントが Work IQ MCP 経由で読めるようになる（GA 展開中）。管理者の統制は、既定オンの Enhanced Personalization をテナントか Entra グループ単位で切ることである。

**詳細**: TC Microsoft Copilot Blog（11/18「The End of Starting Over」）。
- Memory via the MCP tool（GA 展開中）: 最初に読めるのはカスタム指示・保存したメモリ・Copilot のチャット履歴から得たメモリ
- Memory across Microsoft 365 apps（GA 展開中）: Word / Excel / PowerPoint / Workspaces / Pages / Outlook / Teams で、書式や文体の好みを学習する
- Memory citations（GA）: 回答の Sources にある Personalization タブで、使われたメモリと過去のチャットを確認・削除できる
- Email writing style（GA 展開中）と、人・組織コンテキストの拡張（People Skills と組織データは12月までに GA、組織固有の用語は Frontier）
- https://techcommunity.microsoft.com/t5/microsoft-copilot-blog/the-end-of-starting-over-how-work-iq-helps-copilot-understand/ba-p/4571169
