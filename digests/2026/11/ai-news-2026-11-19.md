## 今日のハイライト

### 1. [料金] Chat と Office でも、ライセンスの上限を超えたらクレジット課金でモデルを使い続けられる — 「新サービスを自動で適用」をオンにした既存の支出ポリシーは、何もしなくても課金の対象になる

**要点**: これまで Copilot Chat と Word / Excel / PowerPoint のモデルはライセンスの上限で止まっていた。今後は上限を超えても、支出ポリシーで許可されたユーザーは Copilot Credits を払って同じモデルを使い続けられる。新サービスを自動で適用する設定のポリシーには、このサービスが自動で入る。

**詳細**: MC1557754（11/17）。Frontier では展開が始まっており、全世界での GA は2026年12月上旬の予定。
- 上限に達したとき: Auto に切り替えればクレジットを消費せずに続けられる。UBB が有効なユーザーは、選んだモデルのままクレジットを消費して続けられる
- 管理者の設定: 支出ポリシーに新サービス「Models with usage-based billing in Chat and Office」が加わる。「Auto-apply new services」が有効なポリシーには自動で入り、無効なポリシーには管理者が追加する
- 利用者の画面: 塗りつぶしのクレジットアイコンは課金対象、白抜きは対象外を示す。プロンプトに `/cost` と入れるとセッションの消費が見られる。使えないモデルもピッカーに灰色で表示される
- 関連: MC1483844 の 11/17 更新で、OpenAI をサブプロセッサーとして無効にしたテナントの Cowork でも、Azure 上の GPT-6.1 Sol が GA になり GPT-5.5 を置き換える
- https://mc.merill.net/message/MC1557754

### 2. [新機能+仕様] Copilot Studio の Ignite 発表で Customer Conversation ハーネスとアプリ作成が GA に、分類ノードの既定モデルが変わった — 既存ワークフローの振り分け結果は同じとは限らない

**要点**: 顧客対応の音声・チャット向けハーネスと、Copilot Studio・Cowork でのアプリ作成が GA になった。ワークフローの分類ノードは、既定で判定スコアリングモデルを使うようになった。メール振り分けなどに分類ノードを使っているワークフローは、判定の結果が前と変わる可能性がある。

**詳細**: Copilot Studio ブログ（11/18・製品担当 VP の Ignite 記事）。
- GA: Customer Conversation ハーネス（ライブエージェントへのコンテキスト付き引き継ぎを含む）、Copilot Studio と Cowork のアプリ（今月中に展開）、複数の作成者による同じエージェントの共同編集（エージェント共有）
- パブリックプレビュー: Cowork と Copilot Code から自然言語で Copilot Studio のエージェントとワークフローを作る機能、コマンドラインツールと Copilot Studio MCP
- 2026年12月にパブリックプレビュー: Copilot Studio のエージェント専用アカウント（管理された資格情報で、承認済みのリソースにアクセスする）
- 分類ノード: 判定スコアリングモデルが既定になった。ブログは「より速く、より正確」と書くが、切り替えの時期や従来の挙動に戻す方法は書いていない
- 同日の MC1557509: ワークフローの所有者を、名前付きユーザーではなくサービスプリンシパル（Entra のアプリ登録）にできる。GA は 2026-12-17 まで
- https://www.microsoft.com/en-us/copilot/blog/copilot-studio/build-and-manage-business-processes-with-microsoft-copilot-studio/

### 3. [新機能] Frontier の M365 Copilot ライセンス利用者は、GitHub アカウントなしで GitHub Copilot CLI にサインインできる — CLI の利用料は Copilot Credits から引かれ、管理者が有効にするまで使えない

**要点**: GitHub Copilot CLI の利用には GitHub アカウントとシートが前提だったが、M365 アカウントでサインインし、Copilot Credits でモデルを使えるようになる。既定はオフで、M365 管理センターの Copilot 設定で管理者が有効にする。Copilot Code は Mac とモバイルに広がった。

**詳細**: MC1519871 の 11/17 更新（Frontier 向け）。
- GitHub Copilot CLI: M365 Copilot ライセンスを持つ Frontier の利用者が対象。使用量は従量課金
- モバイル（iOS / Android）: クラウドセッションの開始・継続、承認依頼への応答、結果の確認ができる。ローカルセッションは使えない
- Mac: Microsoft Copilot デスクトップアプリで使える。管理者は対応する版と更新チャネル、テナントでの有効化を確かめる
- Windows のローカル Sandbox: Copilot Code と、Code が起動したプロセスのファイル・ネットワークアクセスを許可した範囲に制限する。有効化できるようになった
- https://mc.merill.net/message/MC1519871
