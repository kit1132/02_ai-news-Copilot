### 2. Copilot Credit の消費が Viva Insights の Consumption Dashboard に出るようになった — 従量支出の可視性が管理センターの外へ出た

**要点**: 直属5人以上のマネージャー・Insights アナリスト・全体管理者が、Cowork と Work IQ API の Copilot Credit 消費をダッシュボードで確認できるようになった。従量支出を把握できるのは管理センターを持つ人だけ、という前提が崩れ、消費を発生させる部門側にも数字が降りる。

**詳細**: Roadmap ID は **566302**。ダッシュボードは**既定で有効**だが、⚠️ **M365 管理センターの Cost Management で使用量ベース課金のセットアップを済ませていることが前提**になる。テナント全体のリーダー向けアクセスは今回のリリースには含まれていない。Insights アナリストと全体管理者には、Advanced Insights に Cost Management のクエリテンプレートが追加される。

8/12 に扱った Agent 365 のコスト管理（M365 管理センターで Cowork と Work IQ のクレジット消費を監視・制御し、ユーザー単位の上限を置く）と対象サービスが一致しており、**制御側と可視化側が同じ2サービスで揃った**形になる。Copilot Studio 側の課金は依然として別系統で、Power Platform 管理センターの Licensing > Copilot Studio から見る。

- https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes
- https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-overview-copilot-credits

### 3. Planner Agent が group-based の basic プランへ広がった — Planner のプラン階層が Copilot エージェント利用の条件から外れた

**要点**: M365 Copilot ライセンスを持つユーザーが、グループベースの Planner プランなら basic でも Planner Agent を使えるようになった。エージェントを使えるかどうかは「Planner の premium プランを買っているか」ではなく「Copilot ライセンスがあるか」だけで決まる形に変わる。

**詳細**: Roadmap ID は **511820**。従来 Planner Agent は premium プラン限定で、タスク実行や状況レポートといった機能はプラン階層に縛られていた。今回の変更で group-based のすべての Planner プランが対象になり、プランのアップグレードなしで同じ機能を使える。

⚠️ **本件は 8/12 まで Message Center の二次スニペット（MC1443514）でしか把握できず、一次未確認として本文に採用していなかったもの**である（B-009）。本日 Release Notes 側で一次確認が取れた。なお MC1443514 が示す展開時期は**8月下旬開始〜9月下旬完了**で、Release Notes の掲載（7/28〜8/11 のバッチ）とは時間軸がずれている。テナントへの実際の到達は8月下旬以降とみておくのが妥当である。

- https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes
