### 1. [廃止] Outlook の Copilot Prioritize が 10/26 から退役を始める — 2027年3月末までに全クライアントから消える

**要点**: MC1519861 によると、Outlook でメールの優先度を Copilot が判定する Prioritize が、10/26 から順にロールバックされる。オプトインは不要で、利用者は退役後この機能を使えなくなる。研修資料や社内手順で Prioritize を前提にした受信トレイ整理は、代わりの手段に置き換える必要がある。

**詳細**:
- 対象: Prioritize を使える利用者。新しい Outlook を含む全 Outlook クライアントから UI が削除される
- 日程: 10/26 に開始し、2027年3月末までに完了する見込み
- 経緯: 10/21 公開、10/22 に v2 へ更新され、日程と本文が改められた（タグは Retirement）
- 管理者の対応は不要。利用者への周知、ヘルプデスクの準備、社内文書・研修資料からの記述削除を推奨している

- https://mc.merill.net/message/MC1519861

### 2. [破壊的変更] Dataverse の Basic User ロールから、カスタムコネクタ定義の読み取り権限が外れる — 共有されていないコネクタは定義が見えなくなる

**要点**: MC1520706 によると、10月中に Power Platform の権限が変わり、Basic User ロールの利用者は、自分が所有するか明示的に共有されたカスタムコネクタの定義しか読めなくなる。これまで環境内のコネクタ定義を一律に読めた前提で作ったメーカー向け手順は、カスタムセキュリティロールの追加が必要になる。

**詳細**:
- 対象: ソリューションに含まれるカスタムコネクタの定義
- 管理者の作業: Basic User のままコネクタ定義を読む必要がある環境を洗い出す。全コネクタを読ませたいときは、Connector テーブルに組織レベルの Read 権限を持つカスタムセキュリティロールを作って割り当てる。メーカー・管理者向けの社内ガイドも更新する
- 理由: 意図して共有していないコネクタの定義や構成を見せないためのセキュリティ強化としている
- 通知は 10/22 公開でタグは Admin impact。発効日は「October 2026」とだけあり、日付は書かれていない

- https://mc.merill.net/message/MC1520706

### 3. [料金+新機能] Copilot Code が 10月下旬から Frontier で展開を始める — 既存のスペンディングポリシーで「新しいサービスを自動で許可」していると、利用者は自動で使えるようになる

**要点**: MC1519871 によると、自然言語でアプリを作る Copilot Code が、M365 Copilot ライセンスと従量課金の対象になっている Frontier 利用者へ展開される。スペンディングポリシーで「Allow new Agents and services as they become available」が有効だと、管理者が何もしなくても Code が使えるようになる。Code の従量課金を避けたい組織は、展開前にポリシーを見直す必要がある。

**詳細**:
- 利用条件: M365 Copilot ライセンスとスペンディングポリシーの両方が必要。課金は従量（Copilot Credits）
- 既定値: クラウドのコーディングセッションは Web と PC で有効。ローカルのコーディングセッション（PC のローカルファイル・ツール・ターミナル）は既定で無効で、M365 管理センターの Code execution location を Cloud and local にすると使える
- 公開と共有: 作ったアプリは Copilot Managed Runtime に公開して組織内で共有できる。データへのアクセスは利用者本人の権限に従う。管理者が有効にすれば GitHub につないでドラフトの pull request を開ける
- 管理者の作業: 統合版 Microsoft Copilot アプリの展開、Frontier 参加の Windows 端末での Copilot のターゲットチャネルを Beta にする設定、M365 管理センターの Copilot > Cost management でのクレジット消費とポリシーの構成
- 経緯: 9/25 に「数週間以内に Frontier で展開」と発表されていた（9/26 既報）。Tech Community ブログも 10/21 に「本日から展開を始める」と書いている

- https://mc.merill.net/message/MC1519871
- https://techcommunity.microsoft.com/t5/microsoft-copilot-blog/copilot-code-make-the-power-of-coding-accessible-to-everyone/ba-p/4562358
