## 今日のハイライト

### 1. [新機能] Dataverse Ask API と Cowork の業務アプリプラグインがパブリックプレビューになった — Dataverse のデータに自然言語で問い合わせる口が API・Cowork・MCP にそろった

**要点**: Power Platform ブログ（10/23）によると、開発者は Dataverse Ask API で、セマンティックモデルを定義して業務データに自然言語で質問できるようになった。Cowork には Business Apps プラグインと Dataverse プラグインが入り、Dynamics 365 / Power Apps の文脈取得と統制付きの操作ができる。これまで Copilot Studio の Work IQ ツールが中心だった業務データへの経路が、カスタムアプリと Cowork にも広がった。

**詳細**:
- Dataverse Ask API: エンドポイントは `/api/iq/v1.0/`（OData の `/api/data/` とは別）。セマンティックモデルの一覧・作成・削除と Ask の4操作で、検索モードは `Auto` / `QuickResponse` / `ThinkDeeper`。上限はユーザーあたり組織ごとに毎分30リクエスト。応答は呼び出し元の Dataverse 権限に従う。Web API と Dataverse コネクタの両方で使える。ライセンスは Work IQ の要件に従う
- Cowork: Business Apps プラグインがパブリックプレビューになり、Dataverse プラグインでローコードのメーカーが環境に接続してデータを管理・照会できる
- その他: Power Apps メーカーポータルの Business Skills にスキル作成・編集のエージェント体験とバージョン履歴が付いた。Copilot Studio の Work IQ MCP サーバーが業務の文脈を理解するようになり、Dataverse MCP サーバーから Custom API を呼べるようになった
- 時期: PPCC 2026 のワークショップ（10/25）と Innovation Session（10/28）に合わせた告知である

- https://www.microsoft.com/en-us/power-platform/blog/2026/10/23/dataverse-and-workiq-ppcc-2026/
- https://learn.microsoft.com/power-apps/developer/data-platform/ask/

### 2. [破壊的変更] Viva Insights の GitHub Copilot 指標が11月中旬から既定でオンになる — オプトインしていない組織でも、既存のレポート閲覧者に開発者の利用状況が見え始める

**要点**: MC1523085（10/23）によると、Viva Insights の消費ダッシュボードで GitHub Copilot 指標が11月中旬から既定で表示され、パブリックプレビューのオプトイン設定は削除される。これまでオプトインしなければ非表示だった開発者の利用データが、既存の閲覧権限を持つ人に自動で見えるようになる。

**詳細**:
- 展開: 全世界で11月中旬に始まり、12月中旬に完了する見込み
- 影響を受ける人: グローバル管理者、グローバルパーティションを持つ Insights アナリスト、消費インサイトにアクセスできるマネージャー
- 何もしない場合: オプトインしていなかった組織でも、関連レポートに既にアクセスできる利用者が GitHub Copilot 指標を見始める。既存のロール・権限・プライバシー設定は引き続き効く
- 管理者の作業: 消費インサイトのアクセス権を見直し、社内の説明資料を更新する。指標を止める設定は残らない

- https://mc.merill.net/message/MC1523085
