### 1. Release Wave が廃止され、Power Platform の計画情報は AI at Work roadmap に移る — 計画を追う場所が9月に変わる

**要点**: 半期ごとの release wave 1 / wave 2 モデルが廃止され、9月以降の新規リリース計画は Microsoft Learn に載らなくなる。**11/15** に Release Planner が退役するため、GA 判定を Learn の緑チェックに置く前提はその日に消える。

**詳細**: Power Platform Blog と Dynamics 365 Blog に 8/25 付で Richard Riley（General Manager, Agents and Low Code）名義の記事が出た。Dynamics 365 / Power Platform / Dataverse のロードマップ情報を **AI at Work roadmap** へ統合し、あわせて「twice-yearly release wave 1 and release wave 2 model」を廃止して継続的な公開へ移す。計画が固まった時点で随時開示する方式になり、半期の発表タイミングまで保留されなくなる。日程は3段階で、① 2026年9月に新機能の AI at Work roadmap への掲載を開始し、同月から Release Plans on Learn への新規掲載を停止、② 9月〜11月に Preview / GA 期日が **2026-06-01** 以降の既存項目を移行、③ **2026-11-15** に移行完了と Release Planner の退役。Release Planner の個人保存ビューは退役後に使えなくなる。移行先は製品とクラウド環境でのフィルター、全件または絞り込み結果の CSV エクスポート、RSS 購読、Release Communications MCP Server 経由でのデータ取り込みに対応する。製品のリリース日程・Message Center 通知・Microsoft Learn のドキュメントは変更されない。⚠️ **移行先の URL は本ダイジェストが毎日巡回している `microsoft.com/en-us/microsoft-365/roadmap` と同一で、ページ表題は既に「AI at Work Roadmap」になっている。**消えるのは Learn の Release Plans と Release Planner の側である。⚠️ **一方で、本日取得した Learn の Release Wave 3ページ（`power-automate` / `power-apps` / `power-platform-governance-administration`）には廃止・移行の注記が一文も入っていない。**

**詳細**: 対象期間は 8/11〜8/25。節構成は Excel 1 / Microsoft 365 admin center 1 / Microsoft 365 Copilot 6 / Microsoft 365 Copilot app 3 / Microsoft 365 Copilot Chat 1 / Microsoft 365 Copilot extensibility 1 / OneNote 1 / Outlook 1 / PowerPoint 2 / Word 2。重いものは4つある。① **Copilot Notebooks の参照ソース拡張**で、Outlook メール（Roadmap 564910）と Teams 会議（同 560706）を知識ソースとして追加でき、会議は文字起こし・メモ・チャット・共有ファイルまで含む。8/13 に一次確認した Markdown / TXT / RTF 対応に続く2段目で、両項目とも Roadmap 側は `Launched` へ移っている。② **Web チャットと Work チャットの統合**で、従来のタブ切り替えが廃止され、チャット UI 左上の Work IQ ボタンで業務データへのアクセスを切り替える（既定はオン）。③ **Excel の Edit with Copilot が Python 実行に対応**し、統計・シミュレーション・高度な可視化の結果をブックへ直接出力する。既存のセキュリティと実行制御はそのまま効く。④ **Word の モデルメニューに Sonnet 5 が入り、既定の推論レベルが引き上げられた**。ほかに Viva Engage のプライベートコミュニティとイベントの内容がグラウンディング対象に入り（515144・閲覧権限のある範囲のみ）、Copilot Search の右ペインから Copilot Chat を使えるようになり（537281）、Researcher のモデルとモードをチャット内で選べるようになった。⚠️ **Cowork の画像生成が OpenAI の ChatGPT Images 2.0 に変わっている**（7/30 に一次確認した時点の記載は Imagen 2 だった）。

### 3. Work IQ ボタンのオン/オフの意味が Microsoft の一次2本で正反対になっている — 8/24 に立てた「一次 vs 二次」という見立ては誤りだった

**要点**: Release Notes は「オンで業務データへのアクセスが有効・既定はオン」と書き、`which-copilot-for-your-organization` は「**オフ**にすると Web の結果も加わる」と書く。食い違いは二次メディアの誤読ではなく、Learn の一次どうしにある。

**詳細**: 8/24 に、MC1458470 を扱う二次が「オフでエンタープライズデータのツールが無効になり Web のみになる」と伝えているのに対し、Learn は逆の説明をしていると記録した。本日の Release Notes（August 25 バッチ・Microsoft 365 Copilot 節）は「Work date is on by default; enable or disable work data access as needed by selecting the button」と書いており、二次の読み方と一致する。一方 `which-copilot-for-your-organization` は本日も「Work IQ ボタンがオンのとき Copilot Chat は Microsoft Graph ベースのチャットになり、オフのときは Entra アカウントがアクセスできる結果に**加えて**インターネットの結果も表示する」と書いたままである（`ms.date` 2026-03-24 / `updated_at` **2026-08-18T17:48Z** で 8/24 から動いていない）。両者は同じボタンについて、片方は「業務データの可否」、もう片方は「Web 結果の追加可否」を切り替えると説明しており、オフにしたときの挙動が噛み合わない。⚠️ **突合先の `support.microsoft.com` は `EGRESS_BLOCKED`、MC 本文の一次である `mc.merill.net` も19日連続で拒否のため、第3の一次で決着させる手段が現時点でない。**
