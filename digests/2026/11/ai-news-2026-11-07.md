## 今日のハイライト

### 1. [廃止] Power Automate のデザイナーの Copilot が 11/30 にサポート終了になる — 自然言語でフローを作る入口は、デザイナーの中から外部の AI アシスタントと MCP に移る

**要点**: 11/30 以降、メーカーは、クラウドフローとエージェントフローのデザイナーで Copilot を使えなくなる。11/30 に退役する Describe it to design it（MC1537406）に続き、デザイナーの中の Copilot 自体も終わる。自然言語での作成・編集は GitHub Copilot などの Power Automate プラグインか、Copilot Studio の MCP 接続に移る。

**詳細**: MC1540258（11/5 公開・Retirement タグ）。
- 残るもの: 既存のフロー（Copilot で作成・編集したものを含む）は削除も変更もされない。デザイナーでの作成・編集・テスト・実行、テンプレートからの開始、式エディター、フローチェッカー、実行履歴は引き続き使える
- 求められる対応: Power Automate と Copilot Studio の利用者への周知
- 代わりの経路: 対応する AI アシスタント（例: GitHub Copilot）の Power Automate プラグイン、または MCP による Copilot Studio への接続
- 非推奨一覧（`important-changes-coming`・`2cc84953`）には、11/7 時点でまだ載っていない
- https://mc.merill.net/message/MC1540258

### 2. [料金+破壊的変更] Opal（Frontier）が 11/9 から従量課金と支出ポリシーの割り当てを前提にする — 支出ポリシーのない利用者は Opal を使えなくなるおそれがある

**要点**: 11/9 から、Opal（M365 の Computer Use Agent・Frontier）を使うには、テナントで Copilot Credits の UBB を設定し、利用者に支出ポリシーを割り当てる必要がある。これまで Learn の設定手順は、M365 管理センターでユーザーグループを選ぶだけで、課金の設定を求めていなかった。

**詳細**: MC1540330（11/5 公開・New feature / Admin impact）。
- 影響を受ける人: テナント管理者と、Opal（Frontier）を使う利用者
- 管理者がすること: 広く展開される前に、M365 管理センターで UBB を設定し、必要なユーザー・グループに支出ポリシーを割り当て、Copilot Credits のコスト管理を見直す
- Learn の状態: `opal-settings-manage`（`copilot/manage/` へ転送・11/4 18:33Z `a5ed557d`）は「Frontier と Copilot サブスクリプションで使える」「Copilot > Settings の Opal (Frontier) でグループを選ぶ」と書くだけで、UBB と支出ポリシーには触れていない
- https://mc.merill.net/message/MC1540330
- https://learn.microsoft.com/en-us/copilot/manage/opal-settings-manage

## Copilot Studio / Power Platform

- [仕様] **ガイダンスハブの新記事「Design reliable agentic loops」**（11/6 19:04Z `d5776a45`・`ms.date` 11/5）— メーカーが Microsoft Copilot ハーネス（旧名 GitHub Copilot ハーネスの表記のまま）のエージェントで、再試行の上限と停止条件を設計するための指針が公開された。記事は、指示だけでは実行が止まる保証にならないとして、上限はツールかランタイムで強制するよう求めている
  - 推奨する制御: 引き継ぎの入出力の契約、必要なツールだけの有効化、状態が変わったかを確かめてからの再試行、Pre tool use / Error / After tool failure のフック、取り消せない操作の前の人の確認
  - 失敗シナリオ7件: あいまいなツールの結果、ランタイムとスキルの要件の衝突、呼び出し側と接続先のエージェントの完了条件のずれなど
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/agentic-loops-in-practice
- [新機能] **Power Pages のプラグインが従来型サイトに対応した**（Power Platform ブログ・11/6）— 開発者は、GitHub Copilot CLI と Claude Code 用の Power Pages プラグインで、Web テンプレートと Liquid で作る従来型（非 SPA）のサイトもプレビューで作成・編集できるようになった。これまでは React などの SPA だけが対象だった
  - 新規作成は拡張データモデル（Bootstrap v5.0）が前提で、環境管理者が設定を確かめる必要がある。手元の編集は公開サイトに反映されず、デプロイには別の承認が要る
  - https://www.microsoft.com/en-us/power-platform/blog/power-pages/create-and-edit-non-spa-power-pages-sites-with-agentic-coding-tools/
