## 今日のハイライト

### 1. [新機能+仕様] Agent 365 で、エージェントの統制ルールとカスタム MCP サーバーの承認経路が使えるようになった — ツール統制は MCP からプラグイン・スキル・コネクタへ広がり GA した

**要点**: 管理者は M365 管理センターで、条件に応じてエージェントを自動でブロックしたり公開要求を却下したりするルールを作れるようになった（プレビュー）。開発者が登録したカスタム MCP サーバーは、管理者の承認を経ないとエージェントから呼べなくなる。統制が「一覧を見て手で止める」から「条件で自動適用する」に変わった。

**詳細**: 一次は Tech Community の Agent 365 Blog「What's new in Agent 365 - September 2026」（9/30 16:00Z・ba-p/4560803）。同ブログの更新は 8/6 の7月版以来である。Agent 365 の登録エージェントは5月の提供開始から約 **5,000万**、数万組織に達したと書いている。

- Agent Management Rules（プレビュー）: 所有者の有無・タグ・Entra Agent ID・発行元・リスクシグナル・利用状況などを条件に、ブロック・公開要求の却下・ポリシーテンプレートの適用を自動で実行する
- Tools management（GA）: MCP サーバーに加え、プラグイン・スキル・コネクタもテナント全体で許可・ブロックできる。Power Platform コネクタの統制は対応中である
- カスタム MCP サーバーの承認（9月にプレビュー）: 開発者が Agent 365 CLI で登録し、管理者が説明・発行元・要求者・エンドポイント・機能を確認して承認・却下する
- AI mode（プレビュー）: レジストリを自然言語で検索し、所有者のいないエージェントや非アクティブなエージェントを洗い出せる
- Azure API Management 連携: 9/30 から展開。APIM に載せたエージェント・ツール・モデル・MCP サーバーが Agent 365 に自動で検出される
- 支出ポリシーによるモデル制限: グループごとに使えるモデルと推論の強さを割り当てられ、Cowork の Auto が選ぶモデルもこれに従う（Cowork で展開中）
- コスト管理の対象: Cowork・Work IQ に Code と Copilot Managed Runtime が加わった。Copilot Studio のエージェントは10月予定（既報）

- https://techcommunity.microsoft.com/t5/agent-365-blog/what-s-new-in-agent-365-september-2026/ba-p/4560803

### 2. [料金+新機能] Copilot in SharePoint で、PDF の分割・結合、版の復元、メール送信、プラグイン呼び出しができるようになった — 画像生成・高速自動入力・サイト分析は今月から Copilot Credits を消費する

**要点**: SharePoint の利用者は、Copilot に頼んで PDF を分割・結合し、ファイルを以前の版に戻し、生成したレポートをメール本文として送れるようになった。大半は M365 Copilot ライセンスに含まれる。画像生成・Advanced Autofill・サイト分析の3つは、今月展開が始まる Copilot Credits の消費対象である。

**詳細**: 一次は Tech Community の SharePoint Blog「What's new in Copilot in SharePoint: October 2026」（10/1 17:44Z・ba-p/4535423）。GA の展開は 9/30 に始まった（9/25 発表・既報）。

- ライセンスに含まれるもの:
  - PDF 操作: ページや節の単位で抽出・挿入・並べ替え・分割ができる
  - 版の履歴: 変更点を要約し、指定した版に戻せる
  - メール送信: 「上司」「部下」のような呼び方から宛先を解決し、送信前に内容を確認できる
  - プラグイン: GitHub や CRM などの外部システムを読み書きできる。一括操作には人の承認が要る
  - HTML: コメントで修正を指示でき、ページライブラリに置けば SharePoint ページとして表示される
  - ワークフロー: Teams にアダプティブカードで通知できる。Power Automate へのアクセスが必要
- Copilot Credits が必要なもの: 画像の生成・編集、Advanced Autofill（大半のファイルが数分、混雑時は約1時間で終わる優先キュー）、サイト分析レポート

- https://techcommunity.microsoft.com/t5/microsoft-sharepoint-blog/what-s-new-in-copilot-in-sharepoint-october-2026/ba-p/4535423
