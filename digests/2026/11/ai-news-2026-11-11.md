## 今日のハイライト

### 1. [廃止+破壊的変更] EU / EFTA のテナントで 12/9 に Claude モデルが既定で有効になり、「M365 アプリの Copilot だけで許可」の選択肢が退役する — EU の Claude は「既定オフで、必要なら有効化する」から「既定オンで、不要なら 12/9 までに無効化する」に変わった

**要点**: 12月上旬に Claude モデルの処理が EU Data Boundary の内側に移り、12/9 には Anthropic を選んでいないテナントで全ユーザーに有効になる。「M365 アプリの Copilot だけで許可」を選んでいたテナントも All users に移る。使わせない組織は、12/9 までに No users か Specific users and groups を選ぶ必要がある。

**詳細**: MC1546438（11/10 公開・Major change・Act by 12/9）。
- 対象: EU Data Boundary の対象になる EU / EFTA のテナント。Copilot の各体験と Copilot Studio で Claude モデルが使えるようになる
- 設定の場所: M365 管理センター > Copilot > Settings > View all > AI providers operating as Microsoft subprocessors > Anthropic。AI 管理者かグローバル管理者のロールが要る
- 既存の選択: All users / No users / Specific users and groups は尊重される。既に有効にしているテナントは、処理が自動で EU Data Boundary 内に移る
- 範囲外: Anthropic models with Data Retention（11/9 掲載）は別の設定で、今回の変更に含まれない。12月上旬までは Claude モデルは EU Data Boundary の処理の約束の対象外である
- https://mc.merill.net/message/MC1546438

### 2. [廃止+破壊的変更] Power BI の単体の Copilot（preview）が2027年1月中旬に退役し、12/8 から M365 Copilot in Power BI が既定でオンになる — Power BI の AI 支援は、単体の Copilot ではなく M365 Copilot になる

**要点**: Power BI のホーム・モバイルアプリ・Teams・ワークスペースアプリにある単体の Copilot が退役し、テナント設定「Show Copilot in app navigation」なども消える。代わりに 12/8 から、M365 Copilot in Power BI and Microsoft Fabric（preview）が全世界で既定オンになる。

**詳細**: MC1546429（11/10 公開・Retirement・Act by 12/8）。
- 消えるもの: 単体の Copilot の入口（ホーム、モバイル、Teams、アプリ単位の Copilot）と、単体の Copilot のテナント設定
- 日程: 12/8 に M365 Copilot の既定オン（全世界）。2027年1月中旬に単体の Copilot が退役する
- 推奨: 利用者への周知と、12/8 までに M365 Copilot in Power BI の提供条件・要件を確かめること
- https://mc.merill.net/message/MC1546429

### 3. [破壊的変更] UBB の Cowork / Code / Autopilot の入口が、2027年1月末から M365 Copilot ライセンス保有者全員に既定で表示される — 管理者が有効にした人にだけ見える機能ではなくなり、見せ方を新しい設定で決めることになる

**要点**: 支出ポリシーで許可されていない利用者にも入口が表示され、「Request access」か「Learn more」が出るようになる。新しい管理設定「Access requests to usage-based billing experiences」が11月中旬に入り、1月末に旧設定「Allow users to discover and use AI experiences enabled by usage-based billing」が退役する。

**詳細**: MC1546354（11/9 公開・Major change）。MC1479277 の告知を、顧客の声を受けて延期・拡張した。
- 11月中旬: 新しい設定が使えるようになる。アクセス要求を出せる利用者を選べ、要求を出させないこともできる
- 12月中旬: 「Specific users」か「No users」を選んだとき、組織のガイダンスへの独自 URL を「Learn more」に設定できるようになる
- 2027年1月末: 新しい表示と設定が強制され、旧設定が退役する。Deferred release の顧客は2月末
- 課金: 実際の利用と課金は、これまでどおり支出ポリシーで決まる
- 関連: MC1479277（9/25 公開）も 11/9 に「Copilot アプリの UI 更新」の節が改訂された
- https://mc.merill.net/message/MC1546354

## Copilot Studio / Power Platform

- [新機能] **Power Platform の10〜11月の月次まとめ**（Power Platform Blog・11/10）— 製品チームが PPCC の発表を含む月次の機能更新をまとめた。作成エージェント、Cowork の Power Platform 管理プラグイン、Work IQ のビジネスアプリ、デスクトップフローのスケジュールトリガーは既報で、未掲載だったのは次のとおり
  - 監視アラートのトリガー: Power Platform for Admins V2 コネクタに「when an alert fires」トリガーが加わり、管理者は監視のアラートを Teams や Azure DevOps などコネクタでつながる先へ送れるようになった（preview）
  - 監視メトリクスのエクスポート: 管理者は監視のメトリクスを API で OpenTelemetry 形式で書き出し、30日の保持期間を超えて自分のストレージに残せるようになった（preview）
  - `Dataverse.Unmask`: キャンバスアプリから、マスクされた Dataverse 列の値を明示的な操作で表示できるようになった。表示には読み取り権限（unmasked）が要る
  - モダンコントロール: 添付ファイル（preview・フォームの外でも使える）、アバターグループ、ペルソナ、メトリクスカード、カードギャラリーが加わった。ナビゲーションやカルーセルなどは2026年末が目標である
  - デスクトップフローのテンプレート: メーカーは、エラー処理やログ記録をまとめたデスクトップフローをテンプレートとして公開し、そこから独立したコピーを作れるようになった
