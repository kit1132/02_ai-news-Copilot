## 今日のハイライト

### 1. [仕様] GitHub Copilot ハーネスが「Microsoft Copilot ハーネス」に改名された — 名前が変わるだけで、機能も課金も変わらない

**要点**: Copilot Studio の GitHub Copilot ハーネスは、Microsoft Copilot ハーネスという名前になった。既存のエージェントの機能と課金は変わらない。製品の画面の表記は今後数週間で切り替わる。Learn の課金ページや研修資料に残る「GitHub Copilot ハーネス」は、旧名として読み替える必要がある。

**詳細**: Copilot ブログ（10/28）による。改名の理由は、このハーネスを Copilot Studio 以外の Microsoft の Copilot 製品にも共通の基盤として広げるためとしている。
- 社内評価（2026年10月）: 同じタスクで標準ハーネスと比べると、合格率は OpenAI のモデルで 10.8ポイント、Anthropic のモデルで 22.1ポイント高かった。ツール呼び出しが失敗したあとも解決を続けた割合は 84〜91%（標準ハーネスは7%未満）。モデルの呼び出しは約2倍に増えたが、キャッシュが効いて入力処理の正味のコストは 15〜21% 下がった
- 社内事例: Microsoft のカスタマーサポート部門のエージェントは、2026年8月に、人の手を介さずに解決した割合が35%を超えた
- Roadmap 576272 の題名も 10/28 20:19Z の更新で「Computer Use for web browsing on Microsoft Copilot Harness」に変わった（`In development`・GA January CY2027）
- Learn 側は 10/29 時点でまだ旧名のままである（`agents-experience/overview` は「Agents powered by the GitHub Copilot Harness overview」、`manage-usage-github-copilot-harness` も URL・題名とも旧名）
- https://www.microsoft.com/en-us/copilot/blog/copilot-studio/the-github-copilot-harness-in-copilot-studio-is-now-the-microsoft-copilot-harness/

### 2. [料金+新機能] Release Notes の新バッチで、Work IQ API の従量課金と、管理者が作るカスタム MCP コネクタがリリースされた — Copilot にデータをつなぐ口と課金の前提が、ライセンス割り当てから従量に広がった

**要点**: 開発者は、ライセンスを事前に割り当てなくても Work IQ API を呼べるようになり、呼び出したエージェントとモデルに応じて従量で課金される。管理者は、M365 管理センターでカスタム MCP コネクタを作り、組織全体に展開して自社データを Copilot に出せるようになった。

**詳細**: M365 Copilot Release Notes の October 27, 2026 バッチ（対象期間 10/13〜10/27）による。前のバッチ（October 06）から22日あいた。
- Work IQ APIs: Usage-based billing（Roadmap 559017）: ライセンスの割り当てが要らなくなり、リクエストごとに呼び出したエージェントとモデルの固定費または変動費で課金される
- Work IQ APIs - Endpoints: Declarative Agent Access（Roadmap 559019）: アプリケーションが Work IQ エンドポイントから、Microsoft 製とテナント定義の宣言型エージェントをプログラムで呼び出せる
- カスタム MCP コネクタ（Roadmap 501585）: 管理者が M365 管理センターの Copilot 拡張機能の画面で MCP ベースのコネクタを作り、組織全体に展開する
- 検索結果のコネクタ表示（Roadmap 502533）: Copilot の検索結果で、コネクタのデータがリンクではなくメタデータ付きのエンティティカードで表示される
- https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes
