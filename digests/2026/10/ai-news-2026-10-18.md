## 今日のハイライト

### 1. [廃止+破壊的変更] SharePoint / OneDrive の `.agent` 形式エージェントは 2027年3月末で動かなくなる — サイトごとに作ったエージェントは Agent Builder へのアップグレードが前提になった

**要点**: MC1511052 によると、SharePoint と OneDrive で作る `.agent` ファイル形式のエージェントは 2027年3月末まで動き、その後は SharePoint・Teams・Copilot アプリのどこでも使えなくなる。11月中旬からは新規作成が Microsoft Copilot Agent Builder に切り替わり、`.agent` ファイルは作られない。サイト単位のエージェントは移行計画が必要になった。

**詳細**: 10/16 公開・SharePoint Online・Admin impact。本ダイジェストへの掲載歴はない。

- 展開: エージェントの作成とアップグレード機能は11月中旬〜12月上旬に展開される。`.agent` 形式の停止は 2027年4月上旬〜4月中旬に展開される
- 移行先は用途で分かれる
  - サイト内の質問応答: Copilot in SharePoint
  - サイト固有の定型タスク: `convert-agent-file-to-skill` スキルで `.agent` ファイルを Copilot in SharePoint のスキルへ変換する
  - Microsoft 365 全体での会話体験: 宣言型エージェントへアップグレードする。SharePoint チャネルに出したカスタムエンジンエージェントは更新する
- 作成者の作業: SharePoint のビルダーに出る **Upgrade to M365 Agent** ボタンでアップグレードする。アップグレードしたエージェントは Teams のチャット / チャネルに追加し直す必要がある
- 停止するもの: Agent Link Web パーツ、イマーシブ表示、SharePoint のチャットペイン。代わりに Agent Chat Web パーツで Plugin store の任意のエージェントをページに置ける
- 管理者の作業: エージェントを持つチームを洗い出し、2027年3月の期限を周知する。アップグレード後は Agent Builder・Plugin store・Agent 365・管理センターで統制する
- 対象クラウド: Worldwide と Government クラウドの両方

- https://mc.merill.net/message/MC1511052

### 2. [廃止] Copilot Studio の Teams アプリは 2027年1月に編集できなくなり、2月に Teams から削除される — Teams 内で作ったクラシックエージェントの保守は Web アプリへ移す必要がある

**要点**: MC1511056 によると、Teams アプリ版の Copilot Studio は、作成機能の終了（6/30）に続いて 2027年1月から既存エージェントの編集もできなくなる。2月には Teams から削除される。Teams アプリ版の画面を前提にした手順書・研修・ヘルプデスク案内は、`copilotstudio.microsoft.com` の Web アプリ版へ書き換えが必要になった。

**詳細**: 10/16 公開・Major change・Retirement。Teams アプリでの作成終了は 6/30 に掲載済み（MC1315217）で、編集の終了日と削除日は本日はじめて確認した。

- 展開: 2027年1月上旬に始まり、2月上旬に完了する
- 対象: Teams アプリ版でクラシック形式のチャットボットエージェントを作成・編集・公開・管理している利用者と、その案内をしている管理者・サポート担当
- Web アプリ版では、クラシック形式のエージェントの作成・編集・公開・管理を続けられる
- コンプライアンス上の考慮事項は「特定されていない」とされる

- https://mc.merill.net/message/MC1511056
