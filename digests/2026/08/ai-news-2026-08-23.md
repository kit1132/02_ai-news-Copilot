## 今日のハイライト

### 1. Copilot のメモリが保持ポリシーの対象になる — 「メモリは統制の外」という前提が9月に崩れる

**要点**: Roadmap に **569612** が起票され、Copilot メモリが Purview のデータライフサイクル管理で保持・バージョン管理できるようになると分かった。メモリは Exchange メールボックスの隠しフォルダーに置かれており、保持・調査の対象外として扱ってきた前提が GA で変わる。

**詳細**: Feature ID **569612**「Microsoft Purview: Data Lifecycle Management – Retention for Copilot Memory」は **2026-08-21 起票**、状態 `In development`、GA 期日 2026年9月、Web、Worldwide (Standard Multi-Tenant) である。本ダイジェストに掲載歴はない。記載されている内容は次のとおり。

- 対象データ: 保存されたメモリと、チャット履歴から推論された詳細の両方を含む。これらが Copilot のパーソナライズと文脈把握を支えている
- 保管場所: **ユーザーの Exchange メールボックス内の隠しフォルダー**に格納されると明記された。保持ポリシーの適用対象になり得る根拠がここにある
- 適用範囲: 保持とバージョン管理が効くのは**非アクティブなメモリ項目**であり、アクティブなメモリは引き続き Copilot 体験の側が管理する
- 想定用途: セキュリティ・コンプライアンス・調査（investigation）のためにメモリ項目の履歴バージョンを保全することを挙げている

⚠️ **現時点の一次は Roadmap 項目だけである。**Purview の What's new にも M365 Copilot Release Notes にも本件の記載はなく、管理者が実際に何を構成するのか（既存の保持ポリシーで拾えるのか、専用の場所が増えるのか）は Roadmap の記述からは読み取れない。

- https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=569612

### 2. 組織プロンプトの公開が管理者の専権でなくなる — 管理センターの権限を渡さずに公開担当を置ける

**要点**: Roadmap の **569425** により、管理者が組織プロンプトの公開権限を利用者や Entra のグループへ委任できるようになる。従来は Microsoft 365 管理センターにアクセスできる人だけが組織プロンプトを置けたため、公開の担い手を広げるにはテナント管理権限を配る必要があった。

**詳細**: Feature ID **569425**「Delegated prompt publishing for organization prompts」は **2026-08-18 起票**、状態 `In development`、GA 期日 2026年9月、Desktop / Web、Worldwide (Standard Multi-Tenant) である。本ダイジェストに掲載歴はない。

- 委任先: 個々のユーザー、Entra ID のセキュリティグループ、配布グループを指定できる
- 委任された側ができること: テナントレベルの組織プロンプトを **Prompt Lab** から作成・編集・削除できる。**Microsoft 365 管理センターへのアクセスは不要**である
- 管理者に残るもの: 従来どおり管理センター側の体験で監視と監督を続けられる
- 前提: 管理者が Copilot アプリのホーム画面に組織向けカスタムプロンプトを配置できる「組織プロンプト」機能の後続にあたる

- https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=569425

### 3. Federated Copilot Connectors が政府クラウドへ GA する — インデックスを作らない接続方式が規制環境でも選べるようになる

**要点**: Roadmap の **569212** で、Federated Copilot Connectors が GCC / GCC High / DoD 向けに 2026年9月 GA と示された。顧客データを Microsoft 側に保存・インデックスせず MCP で都度取得する方式が、これまで対象外だった政府クラウドの選択肢に入る。

**詳細**: Feature ID **569212**「Federated Copilot Connectors in Microsoft 365 Copilot」は **2026-08-18 起票**、状態 `In development`、GA 期日 2026年9月、Desktop / Mac / Web である。`cloudInstances` は **GCC / GCC High / DoD の3つのみ**で、Worldwide は含まれていない（Worldwide 向けは 2026-05-05 の M365 Blog で公開済み）。

- 取得方式: **Model Context Protocol (MCP)** でサードパーティのソースからリアルタイムに取得する
- データの扱い: **顧客データを Microsoft 側に保存もインデックスもしない**。アクセスは利用者自身の ID で都度行われる
- 統制: 管理者は Microsoft 365 管理センターからガバナンスと制御を保持する
- GA 時の露出先: **Researcher エージェントと Microsoft 365 Chat** の両方で使えるようになる

- https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=569212
- https://www.microsoft.com/en-us/microsoft-365/blog/2026/05/05/federated-copilot-connectors-bringing-real-time-enterprise-data-within-microsoft-365-copilot/
