### 1. Copilot Business の従量課金が既定オンになる — 新規購入が「課金経路なし」ではなく「月$10の枠つき」で始まる

**要点**: 11/2 以降、CSP 経由で新規購入する M365 Copilot Business は従量課金が既定で有効・$10/ユーザー/月の枠つきで始まる。課金経路は購入後に管理者が有効化するもの、という前提が崩れ、判断が「有効化するか」から「枠を絞るか」へ変わる。

**詳細**: Partner Center の9月アナウンスに **2026-09-16** 付で「Usage-based billing will be default-on for new Microsoft 365 Copilot Business licenses starting November 2, 2026」が追加された（掲載歴ゼロ）。ページは `updated_at` が 2026-09-10T16:02Z から **2026-09-16T16:02Z** へ動き、掲載9件から11件に増えている。

- 発効日: 2026-11-02
- 対象: CSP 経由の Microsoft 365 Copilot Business の**新規購入**（単体・バンドルとも）。既存ライセンスへ遡及するとは書かれていない
- 既定の上限: USD $10/ユーザー/月の従量課金枠。上限の変更と前払いクレジットの追加は顧客側で可能
- 対象体験: Copilot Cowork / Work IQ API / GitHub Copilot ハーネスの3つ
- 同梱されるもの: 従量課金に必要な Azure サブスクリプションのセットアップが新規ライセンスに含まれ、複数手順の課金構成が不要になる

⚠️ 本件は 9/14 に検知したクレジット統制ガイダンスの前提を1つ外す。 同ガイダンスは統制を4層（テナント / 環境 / エージェント / 運用プロセス）で設計するよう求めていたが、そこでは課金経路の有効化そのものが最初の関門だった。11/2 以降の新規購入では関門が無くなり、初期状態で月$10×ユーザー数の消費余地が開いた状態から統制を始めることになる。

### 2. Graph PowerShell が Windows PowerShell 5.1 を12か月で退役させる — テナント自動化の実行基盤に期限がついた

**要点**: Microsoft Graph PowerShell が Windows PowerShell 5.1 向けの保守を12か月かけて打ち切り、Q4 CY2026 に出る v3.0.0 は 5.x を明示的にサポートしない。5.1 で動く運用スクリプトが「当面このまま動く」から「移行期限のある資産」へ変わる。

**詳細**: M365 Developer Blog に **2026-09-16 16:02Z** 付「Investing in a more reliable Microsoft Graph PowerShell experience」が公開された（掲載歴ゼロ）。Microsoft は投資先を PowerShell 7.x 以降へ集約する理由として、7.x が新しい .NET 上に構築されており、Windows PowerShell 5.x で起きるアセンブリ読み込みと依存関係の問題を解消している点を挙げる。

- 退役の意味: 互換性ではなく**保守**の打ち切りである。v2.x は退役期間を通じて Windows PowerShell 5.1 との互換を宣言し続け、多くの環境でこれまで通り動く
- 退役期間（今後約12か月）: v2.x は必要に応じてセキュリティ修正を受ける。新機能・バグ修正・検証は PowerShell 7.x 以降を対象とし、5.x 固有の問題は今後調査も修正もされない
- Q4 CY2026: 新しいメジャーバージョン v3.0.0 が出る。以降はセキュリティ修正が要る場合を除き v2 の新バージョンは公開されず、v3.x は PowerShell 7.x のみのサポートになる
- 記事は「今日切り替えるスイッチではなく計画された移行」と明記し、5.1 利用者に対して今から 7.x への移行計画に着手するよう求めている

- https://devblogs.microsoft.com/microsoft365dev/investing-in-a-more-reliable-microsoft-graph-powershell-experience/

### 3. Purview のネットワークデータセキュリティが GA した — 生成 AI への持ち出し遮断が「プレビューだから本番に張れない」ではなくなった

**要点**: Entra Global Secure Access と連携してネットワーク層で DLP を適用する機能が GA した。ChatGPT・Gemini・Claude 等への送信を監査またはブロックできる。shadow AI 対策をプレビュー扱いで保留していた前提が外れ、必要なのは設計ではなくライセンスの判断になる。

**詳細**: Purview What's New の `updated_at` が 2026-08-28T07:31Z から **2026-09-16T17:34Z** へ 19日ぶりに動き、**September 2026** 節が新設された。9月節の掲載はこの1件のみで、7月節では同じ組み合わせが (Preview) だった。既存の分類子・収集ポリシー・DLP ポリシーをそのままネットワーク層へ広げる仕組みである。

- 検出対象: 生成 AI（ブラウザー・アプリ・アドイン経由）/ 未承認クラウドストレージ（Dropbox・Box・Google Drive）/ クラウドメール（Gmail）/ オンラインフォーム / SNS
- アクティビティ4種: テキスト送信・ファイルアップロード・テキスト受信・ファイルダウンロード。アクションは Audit only と Block の2つで、Entra GSA は全アクティビティ・全アクションに対応する
- ライセンス: GSA 連携は **Microsoft 365 E7** 単独、または Purview E5 相当 + Entra Internet Access 相当のいずれか。非 Microsoft の SASE / セキュアブラウザー連携は Purview E5 相当 + Purview の従量課金が要る（GSA 連携に従量課金は不要）
- 適用範囲の制約: B2B ゲストには適用されない。インライン評価の上限はテキスト 4 MB・ファイル 3 MB。ポリシー配布に最大24時間、アクティビティが監査ログと Activity explorer に出るまで最大30分かかる
- データソース: Defender for Cloud Apps のカタログにある 35,000超のクラウドアプリと、生成 AI・クラウドストレージ・共同作業・SNS・Webメール等のカテゴリ別スコープを指定できる

⚠️ 未管理クラウドアプリとしての扱いは Microsoft Copilot の消費者版だけに掛かる。 企業版 Copilot は本機能の対象外で、保護は既存の Enterprise data protection 側に載る。同じ「Copilot」でも統制経路が分かれる点はポリシー設計時に効く。

⚠️ ライセンス経路の片方は 9/30 に条件が変わる。 GSA 連携の単独経路である M365 E7 はプロモーション最終日が **9/30** である。E7 を前提に本機能を設計する場合、価格条件の確定は今月中の判断になる。

- https://learn.microsoft.com/en-us/purview/whats-new
- https://learn.microsoft.com/en-us/purview/dlp-network-data-security-learn
